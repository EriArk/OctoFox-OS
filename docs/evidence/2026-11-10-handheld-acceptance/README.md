Flip использовала Software 10/runtime 17 и временный локальный профиль setup;
оригинальные профили были отложены ещё 4 ноября. Они сохранены вместе с текущими.
После обычного выхода в Desktop проверены все 222 записи нового архива профилей
и 215 записей архива загрузочных настроек; обе копии прочитаны и проверены на сервере.
Полный предыдущий Setup (1 823 354 880 байт) проверен SHA-256 на Flip и сохранён.
Удалён только устаревший экспорт контейнерного образа (2 181 533 696 байт);
сам установленный образ сборщика, активная установка, откат и личные файлы сохранены.

Официальный updater Armada подготовил 20261109.3e75201, затем обычное меню Desktop
выполнило Restart. bootc сообщает эту версию как booted, staged отсутствует,
rollback — 20261025.1ed5b2b. Установленный TrainerOS запущен автоматически.
Это проверка обновления ОС и прежней установки, не новый чистый цикл Setup.

## Ключ Software

Закрытый ключ прежнего выпуска находился на удалённой Windows. Поиск в доступных
копиях проекта, каталоге владельца и на сервере не нашёл его. Новый ключ сохранён
в закрытом каталоге владельца и отдельно на сервере. В репозитории только публичные
ключи: текущий trusted-release-key.pem и прежний trusted-release-key-2026-11-04.pem.
Старый установщик остаётся самодостаточным комплектом отката. Старые установки
не начнут доверять новому OTA автоматически: переход требует нового Setup.
Проверки подписей не отключаются; публикация нового пакета ещё не выполнена.
