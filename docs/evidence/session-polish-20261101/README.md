# Завершение Plasma и яркость — 1 ноября 2026

Продолжение [предыдущей поставки](../steam-return-20261101/README.md), S15/R117.
Исправления установлены на Odin и Flip. Бинарник TrainerOS не пересобирался:
`b667747b3adcd0833aac1b7ca6e5e25324668f912e53dff38852be760333cabf`.
Профили, сохранения и пакеты аватара не заменялись.

## Причины и изменения

1. **Яркость.** KWin загружал сохранённые примерно 33% из
   `kwinoutputconfig.json` и заменял текущую аппаратную яркость. Пользовательский
   `ExecStartPre` перед запуском standalone KWin переносит текущее значение
   единственного встроенного экрана. Диапазон `[1,max]` соответствует
   [KWin externalbrightness_v1](https://invent.kde.org/plasma/kwin/-/blob/5b7302c5414004c2f876abcb83eb02309b8a4581/src/wayland/externalbrightness_v1.cpp).
   Геометрия/поворот/масштаб/внешние экраны сохраняются; первая копия конфигурации
   остаётся рядом. Запись атомарная, параллельная правка не заменяется.
   HDR, автояркость, неоднозначные экраны, выключенная подсветка, ссылки и
   отсутствующий/неизвестный формат конфигурации пропускаются. Это исправление
   проверенных панелей, не универсальная синхронизация произвольного монитора.
2. **Возврат в TrainerOS.** Только при живых KWin + ksmserver и активном unit
   standalone compositor вызывается штатный KDE logout от имени пользователя.
   Один лишь активируемый `org.kde.Shutdown` не считается сессией. Ошибка запроса
   не превращается в принудительное закрытие документов. Вне KDE остаётся
   прежний переход через SDDM. Steam/Desktop-направления не переписаны.
3. **SIGSEGV на Flip.** Штатный logout сам по себе не помог. Живой GDB показал
   поздний деструктор PulseAudioQt: удаление Sink/Port запускает QML-привязки
   текста после уничтожения Qt-приложения и падает в `QThreadStorageData::get`.
   Отдельный патч освобождает аудиомодели на `aboutToQuit` и прекращает reconnect
   при завершении. [Версия, исходники, лицензия, сборка и откат](../../../packaging/host/pulseaudio-qt/README.md).
   Это исправление порядка освобождения, не SIGKILL и не отключение звука.

## Проверки

- На каждом устройстве прошли **7 SessionDesktopTests + 12 SessionSupervisorTests**.
  Новые проверки покрывают отказные пути logout, неверную/неоднозначную конфигурацию
  яркости, резервную копию и сохранение остальных параметров.
- На Windows: **2 PlasmaCompatibilityTests + 4 HostAndOwnershipTests**. Проверены
  fallback после смены системной библиотеки, повреждённого артефакта, ограничения
  архитектуры и удаление только неизменённых принадлежащих нам файлов.
- На Odin собрана PulseAudioQt 1.8.1 с патчем: **4/4 upstream MapsTest**.
  Отдельный probe с настоящим аудиоустройством и QML-привязкой порта завершился
  с кодом **1 на stock / 0 на patched**. Он проверяет живое Qt-приложение при
  удалении порта, пустые модели после выхода и отсутствие позднего reconnect.
  Звук не воспроизводился, громкость probe не меняет.
- **Flip:** Start → Desktop с подтверждением → Plasma Mobile → поиск приложений
  → Return to TrainerOS. До патча SIGSEGV воспроизводился и при штатном logout;
  после патча `plasmashell` PID 52033 и KWin завершились с `Result=success`.
  Новая сессия TrainerOS показывает Home и отвечает на Start. Coredump после
  установки исправленной библиотеки отсутствует.
- **Яркость Flip:** 75% при первом входе в Plasma сохранились; затем штатным
  KScreen выставлены 60%, они пережили возврат и следующий вход в Plasma.
  После проверок через Start восстановлены 75% (`191/255`).
- **Odin:** Start → Desktop → Return to TrainerOS. Plasma PID 44550 и KWin
  завершились успешно; новый `traineros-session.service` активен, сохранены
  75% (`767/1023`), громкость подтверждена 0%. Сразу после этого Odin перестал
  отвечать по SSH и ping, поэтому свежий финальный кадр/ответ Start после
  возврата **не получены**. Это отдельное незавершённое условие; причина потери
  сети пока не установлена, перезагрузка не выполнялась.
- В работающей Plasma на обоих устройствах подтверждены загрузка исправленной
  библиотеки и наличие выходов/входа PipeWire. Это не прослушивание/микрофонная
  приёмка. На Flip после возврата SQLite `quick_check=ok`, preload отсутствует
  в окружении user systemd manager и процесса TrainerOS.
- Удалённые события X11/uinput и захват реального экрана, не физические кнопки.
  Приватные кадры/логи/сборочные материалы: игнорируемые `build/session-polish01`,
  `build/steam-return01`, `build/support29`; сборка и резервные копии на SD.

## Границы поставки

Патч аудиобиблиотеки привязан к проверенной системной версии; изменение stock
или повреждение артефакта возвращает обычную Plasma с сообщением в журнале.
Системные файлы `/usr` не изменены. Установщик умеет принять отдельный собранный
артефакт, но его включение в публичный image/OTA не выполнено этим core-проходом.
Полная переустановка/удаление на живых профилях не проводилась.

Штатные QML-предупреждения Plasma (включая null audio properties при очистке)
остаются; чистым от предупреждений журнал не объявляется. Физические кнопки,
звук на слух, сон, игры/смена аккаунта Steam остаются отдельной приёмкой.
Проверка полного Steam-круга из предыдущего прохода сохраняется, заново здесь
проверялись изменённые Desktop/возврат и яркость. Steam library/#69/R117 открыты.
Ближайшее условие: восстановление доступности Odin и свежий ответ его интерфейса;
следующий функциональный блок после этого — библиотека Steam внутри TrainerOS.
