# Steam library — поставка 1 ноября 2026

[Контракт и входы/возвраты](../../STEAM_LIBRARY.md), #69 / R117.
Core `main`, поверх `eab9078b`. SDK, multiplayer, Crates и installer/OTA
не расширялись; runtime mirror обновлён как обязательный снимок ProcessService.

## Реализовано

- Фоновое обнаружение известных Steam libraries и установленных Game/Demo/Mod;
  локальные обложки, логотипы, фон, разработчик/издатель и дата выпуска.
  Инструменты/Proton не становятся играми, неоднозначная установка не выбирается
  по порядку обхода. Games → Steam использует обычные карточки и Home.
- Стабильные App ID и сохранение личных названий/истории при переносе или отсутствии
  установки. Файлы Steam нельзя переместить/удалить операцией TrainerOS.
- Запуск штатным Steam, подтверждение окна реальной игры, общие Game Options,
  сворачивание/возврат, завершение конкретной группы процессов и история.
  PID/start-time/XRes сохраняют границы между игрой, клиентом и чужими процессами.
- Снимок выхода сохраняется при изменении Steam bookkeeping; App ID/build ID/
  install directory дают только presentation fingerprint, без допуска к save.
  Белые логотипы на светлом фоне получили тонкую тень без перекрашивания.

## Сборка и проверки

Native aarch64 / Qt 6.11.2. Исходники, объектные файлы и контейнер — на microSD.
Production собран с `BUILD_TESTING=OFF`; сверены исходники сборки и установленный
исполняемый файл. Итоговый SHA-256 на **обоих** устройствах:

`0ea60099b04f543e948a533ac5e81bc47e0559c86da23574ef2cf03d552c91b1`

- CTest: `pc_games`, `process`, `steam_library`, `overlay_helper`, `pc_session`
  прошли. `library` сначала превысил таймаут на microSD: ожидание обычного открытия
  fixture-базы заняло более 5 секунд. Полный тот же suite с временными базами
  в RAM прошёл за 9,43 с; исходный timeout не скрыт и не объявлен успешным.
- `history` с новой регрессией снимка Steam прошёл за 11,56 с. Проверены изменение
  LastPlayed между началом/концом, повторное открытие базы, смена build ID,
  повреждённый/дублирующий манифест и сохранение истории.
- Linux Python: SteamLibraryTests 7, OverlayHelperTests 25,
  EmulatorSupportInstallTests 2 — пройдены. Windows-прогон SteamLibraryTests:
  5 пройдены, 2 Linux process cases пропущены и затем выполнены на Linux.
- Проверены split/duplicate/no-ready marker, отсутствие ложного игрового старта,
  перенос/недоступность/переименование и запрет destructive Steam-операций.
- `check-adapter-knowledge.py`: 32 adapter files / 3 exact profiles,
  252 runtime files; `git diff --check` без ошибок.

## Фактические устройства

| Проверка | Flip | Odin |
| --- | --- | --- |
| Обнаружение | 1 запись, 1 доступная игра | 96 записей, 86 доступных установок |
| Реальный запуск | Dead Cells через Games, затем повторно через Home; игровое меню | Celeste через Games; стартовый экран игры |
| Home / Game Options | Открытие, Minimize, возврат в тот же supervisor без нового запуска | Открытие, Continue, повторное открытие |
| Выход | Подтверждение → игра завершена → прежний экран | Подтверждение → игра завершена → прежняя карточка Celeste |
| История и снимок | Два отдельных реальных запуска; во втором снимок записан и виден на Home после перезапуска оболочки | Одна `returned`-сессия; снимок записан, Celeste на Home |
| Итог | TrainerOS, 0 running sessions, Steam остаётся работать | TrainerOS, 0 running sessions, Steam остаётся работать, громкость 0% |

Первый прототип запуска на Flip ждал установки Steam Runtime/шейдеров и завершил
ожидание без ложной сыгранной сессии. После завершения Steam-обновлений реальная
игра открылась. На Odin Steam перед Celeste обновил шейдеры и запустил FEX;
ожидание клиента не попало в игровое время. Dead Cells на Odin показана
недоступной, поэтому для проверки выбрана доступная Celeste, без изменения её
настроек совместимости. Это не исправление/сертификация всех установок.

В первом установленном цикле Flip снимок был получен, но отклонён из-за изменения
Steam-манифеста. Причина исправлена в том же блоке: повторный выход и сохранение
снимка прошли, включая повторное открытие оболочки. Финальная правка тени не меняет
session/storage-код; эта проверка не повторялась без необходимости.

До установки сохранены rollback executable, настройки и SQLite backup. После
поставки обе базы проходят `quick_check`; старые защищённые строки сохранены,
настройки побайтно совпали с исходными, manifest существующего avatar pack не
изменился. Новые запуски и снимки добавлены штатным путём. Финальные хеши helpers
проверены. Сырые логи/снимки с личными профилями остаются в приватных build-артефактах.

## Не принято этим проходом

Home вызван удалённо через существующий канал принадлежащего игре overlay;
навигация и подтверждения — через настоящие UI-действия. Это **не физическая**
проверка кнопок, стиков, сенсора или Steam Input. Нет приёмки долгой игры/FPS,
cloud sync, всех остальных игр, Flatpak и Wayland-only без Xwayland/XRes.
Импорт Steam-ачивок/времени не заявляется. Полный R117 остаётся открытым.
Публичная упаковка прежнего PulseAudioQt host-патча — отдельный installer/OTA
workstream; прежний единичный обрыв сети не объявлен исправленным. Sleep не тестировался.
