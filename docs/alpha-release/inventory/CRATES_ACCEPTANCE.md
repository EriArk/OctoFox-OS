# Crates — приёмка альфа-кандидата

**Статус:** `OPEN` для итоговой публичной альфа-сборки. Прошлые подтверждения есть, но здесь ничего не тестировалось повторно. Любая галочка требует точные **commit, версию пакета, architecture, ОС/устройство, дату, логи и результат**.

## A. Каталог и карточки

- [ ] На чистой установке открывается Online → Crates и шесть контейнеров; порядок и сохранение фокуса корректны
- [ ] Пустой Adventure действительно выглядит пустым, переходы Back/пагинация/скриншоты без падений
- [ ] В offline есть встроенная витрина и понятный статус; ни один пример без release record не притворяется устанавливаемым
- [ ] Сетевой каталог 43 (или актуальная на момент релиза ревизия) загружается/верифицируется на чистом устройстве, отображает Alpha Preview и список проекта
- [ ] По ошибке HTTPS/подписи/сети остаётся ранее проверенный кеш; установленная игра запускается offline
- [ ] `supported` / `untested` / `incompatible` показываются корректно и соответствуют действию, несовместимую архитектуру выбрать нельзя
- [ ] Исправить или принять решение о **неверном Install anyway для incompatible**, см. [CRATES_AUDIT](CRATES_AUDIT.md#6-выявленные-риски-и-несоответствия)

## B. Установка, история, данные и права

- [ ] Первый Download реального пакета, прогресс, hash/payload, регистрация и Play/Open
- [ ] Update вместо Play/Open при новом релизе; Update all с подтверждением, затем правильный возврат к Play/Open
- [ ] Remove: значок, исходный Cancel, B и скрытое действие не удаляют; подтверждение удаляет код **без потери личных данных**
- [ ] Reinstall возвращает те же данные, прежний `crates:<id>` и историю без дубля
- [ ] Пауза/отмена/повтор, очередь нескольких пакетов и HTTP Range возобновление работают при реальном сетевом обрыве
- [ ] Журнал/восстановление после SIGKILL до/после commit без доступа к сети; **физическую потерю питания не симулировать на личных данных**
- [ ] Update/Remove не заменяют живой или минимизированный процесс; отказ понятен
- [ ] Неавторизованные URL, неподписанный каталог, symlink/traversal и чужая ISA отвергаются

## C. Интеграция

- [ ] Всякую установленную `game` можно найти в Games и запустить/закрыть через Game Options с правильным владельцем сейва
- [ ] Установленное `app` появляется в Apps и корректно запускается/минимизируется/закрывается из Quick Apps
- [ ] Session Timer 0.1.0: после запуска появляется Start-widget, можно запустить/поставить на паузу, перестановка панели не ломает работу
- [ ] Известный Timer `Back to TrainerOS` в Gamescope — исправлен или прямо указан обход `Home → Minimize`
- [ ] Companion 0.1.1: Home selection, профиль/аватар, Feed/Rest, смена фона, скрытие/возврат, удаление и восстановление состояния
- [ ] Home-only Companion **не** появляется как пустой Start widget и не загружает downloaded QML в shell
- [ ] На clean install есть необходимая версия shell/SDK для Companion, иначе выводится корректное требование обновить host
- [ ] Проверить внешние inventory изменения: установка/обновление/удаление вне открытой вкладки регистрируется в Games/Apps/SDK

## E. Решение о включении в анонс

- **Можно** описывать проверенный UI, подписанный каталог, общий установщик, списки проектов, вручную проверенные узкие сценарии и заявленные платформы.
- **Можно с пометкой Experimental** описывать отдельно опубликованные, но неполностью проверенные игры/пакеты.
- **Нельзя** обещать рабочие Extensions, все 24 мини-игры, полное P2P/голос/турниры, универсальное plugin SPI, собственный Bazaar или автоматическую поддержку всех Linux устройств.

**Отдельная следующая приёмка:** multiplayer режимы самих Crates-игр — в [MULTIPLAYER](../blocks/INDEX.md) после специального аудита.
