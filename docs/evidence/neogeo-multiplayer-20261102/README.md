# Neo Geo multiplayer — 2 ноября 2026

[Контракт и сопровождение](../../emulators/neogeo-multiplayer.md).

NeoCD: собственный пустой тестовый CD, без игры/BIOS из библиотеки пользователя.
Первоначальная версия дала 26 различающихся байтов между процессами из-за ASLR;
после исправления указателей полная проверка rollback обнаружила четыре
изменённых байта RAM при восстановлении HLE. Исправлен механизм, а не исключён
этот случай из проверки. Дополнительно включена backup RAM в снимок.

Итоговая проверка `check-state.py`: три независимых процесса, одинаковые
контрольные суммы, перенос чужого снимка, повторное проигрывание видео и полного
состояния. Отдельно изменён байт backup RAM после снимка: restore вернул
исходное значение. Размер снимка 8 240 131 байт. Новая сборка использует отдельную версию
состояний; обычные одиночные сохранения не преобразуются.

NGPC: upstream libretro native cable test — 1/1. Дополнительный native mirror
probe на ARM64: четыре эмулируемые машины, разные кнопки сторон, одинаковая
память пары и полученные через BIOS/кабель кнопки соперника. Очередь 0 проходов:
240 кадров на сторону за 2.483 секунды; очередь 6 проходов: 236 кадров за
2.261 секунды. Время получено без вывода видео/звука и не обещает такую же
производительность итогового интерфейса. Прототип не установлен как runtime.

Общие проверки: RetroArchTests — 77/77, RuntimeMultiplayerTests — 105/105,
без пропусков. Они включают новый manifest, изменённый диск/ядро, приватный BIOS,
общие приглашения, запуск и завершение. Отдельный native запуск двух настоящих
процессов текущего RetroArch подтвердил подключение Player 1/Player 2 с новым
ядром в изолированной сети. В журнале нет сообщений о desync/CRC mismatch;
пустой тестовый диск без ISO9660 и отсутствие headless меню/аудио дают ожидаемые
диагностические сообщения. Это handshake и synthetic core-state proof,
не игровой матч и не проверка разных интернет-сетей.

NGPC probe сохранён в [ngpc-mirror-probe.py](ngpc-mirror-probe.py). Аргумент —
рабочая папка с закреплённым checkout `ngpcraft/` и собранным upstream
`ngpc-build/ngpcraft_libretro.so`. Используются upstream `tests/roms/link_probe.ngc`,
HLE BIOS и настоящий NativeMachine; пользовательские ROM/сохранения не нужны.

## Сборка и остановленная поставка

Production-сборка Qt 6.11.2 готова. Проверены 1305 исходных файлов по SHA-256
против дерева на базе `cce39034`; avatar preview включён, BUILD_TESTING выключен,
UI-test compile flags отсутствуют. Исходники, native probes, сборка, пакет
и контейнеры находятся на microSD Flip.

- Кандидат shell SHA-256: `64d695d9da57ca5ef3eee31e2563ece3e0ad2398973a557f71cd02dda7f57bdf`.
- Core SHA-256: `b27bc11deadcdde1d31451149094795b5b417c1e28a8e4dc74a096c567149031`.
- Runtime archive SHA-256: `a1d05f5e52477ffc0cc77b5d3dec4b3ae03c2d55cb25e7a72699ca2bba880954`.
- Пакет содержит ядро, manifest, патч, лицензию и полный соответствующий исходник
  со сторонними notices; ROM/BIOS в него не входят.

Установщик остановился на проверке предыдущего SHA **до первой замены**.
Ожидался прежний Doom binary `abae6ffe…`; на диске и в запущенном процессе уже
`cd15a8a5…`. Локальная запись другого потока `refresh02/flip-final-installation`
подтверждает установленное исправление восстановления входа. Его исходники
в другом checkout ещё незакоммичены; `origin/main` остаётся `cce39034`.
Устанавливать прежнюю основу поверх них нельзя. Отдельный NeoCD-пакет ещё
не установлен, прежний процесс не перезапускался, пользовательские данные
этой попыткой не изменены. Успешный старт новой оболочки не заявляется.
