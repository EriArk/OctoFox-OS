# Apps: Home, Quick Apps и жизненный цикл — 10 ноября 2026

Владелец утвердил исправления анализа Apps и явно потребовал показывать
запущенные/свёрнутые приложения в Quick Apps. Установки отложены до отдельного
возобновления; этот проход не подключается к портативкам.

## Изменения

- `AppControlsWindow` — Home по центру с Return / Minimize / Close application.
  Угловой постоянный HOME убран. Используются существующие Home lease,
  нейтральные барьеры ввода и compositor bridge, без нового менеджера окон.
- Открытие меню не сворачивает приложение; Back/Home возвращает. Close остаётся
  WM_DELETE_WINDOW, без сигналов завершения и обхода диалога сохранения.
- Shell остаётся на исходном экране, вместо принудительного перехода в Apps.
  Возврат из Quick Apps сохраняет выбранное приложение; обновление каталога
  сохраняет фокус сетки по desktop ID, а не случайно сдвинувшемуся индексу.
- Quick Apps не теряет запущенное избранное после уменьшения доступной ёмкости.
  Скрытые живые приложения доступны, дублей нет. Opening / Open / Minimized
  отображаются в сетке и подписи выделенного значка дока.
- Состояние запуска устанавливается сразу, повторное нажатие не посылает второй
  запрос. Ошибки/недоступность запуска из Crates и Files видны в общей notice.
  Ошибка операции с передним приложением возвращает его Home с объяснением.
- Files передаёт URI штатному обработчику и возвращает уже известное окно того же
  приложения; не ждёт обязательно нового окна и не присваивает посторонние окна.
- Browser отличает выбранную страницу от переднего окна, прекращает опрос поля
  ввода за внешним приложением и допускает прежнюю отложенную заморозку Chromium.
  Существующие ограничения заморозки при загрузках и recommendedState сохранены.
