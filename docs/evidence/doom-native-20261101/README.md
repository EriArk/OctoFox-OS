# Doom / Odamex — 1 ноября 2026

[Контракт и обслуживание](../../emulators/odamex.md).
Upstream `3a763534ac609aee8d22351baa3155809c4ea355`, Odamex 12.3.0,
штатные клиент и сервер, без патча игрового протокола.

## Проверено

- RuntimeMultiplayer: **105 passed, 0 failed, 0 skipped**. Общие приглашения,
  подготовка, привязка Ready к месту, запуск/отмена/обрыв/возврат и обновление
  зависимостей. Doom включён в native admission и назначение мест.
- Doom package admission: **3 passed, 0 failed, 0 skipped**. Настоящий
  запечатанный ARM64-пакет; отдельный путь solo, неизменённое собственное
  сохранение, четыре места, повторный запуск/lock, неверная роль,
  изменённый набор и подменённый helper.
- Python content/endpoint: **9 passed** на Linux. Порядок модов, независимость
  от имени, нестандартные имена карт, повреждённый WAD, отсутствующая база, неявный BEX include, подменённый неучтённый Python bytecode,
  разные адреса трёх гостей, границы пакетов до 8192 байт, посторонний
  локальный отправитель, повреждённый фрейм, потеря соединения и закрытый
  локальный контракт подключения.
- Owned-window overlay: **26 passed**, включая распознавание управляемого Doom
  внутри существующего дерева процессов сеанса.
- Настоящие Odamex server/client на ARM64: **2 и 4 клиента**, каждый в своём
  network namespace, SDL dummy, без устройства ввода, звука и пользовательского
  экрана. Свободный Freedoom 0.13.0 — только изолированная тестовая зависимость,
  не добавлен в пользовательскую библиотеку и не включён в runtime-пакет.
  Сервер принял всех клиентов на MAP01; 20 секунд двусторонних native пакетов.
  Разрыв одного carrier-канала остановил собственный сервер, процессы
  клиентов остались открытыми до уборки проверки.
- Дополнительная native-проверка четырёх клиентов с одинаковым IWAD под разными
  именами также прошла: сервер принял все четыре места, обмен продолжался
  20 секунд, потеря carrier остановила сервер и сохранила процессы клиентов.
- В первом запуске тест ошибочно искал native acknowledgement в stdout клиента:
  Odamex выводит его во внутреннюю консоль. Критерий исправлен по upstream:
  admission/map события dedicated server плюс живые клиенты и обмен пакетами.
  Окончательные 2/4 проверки прошли; пустой клиентский stdout не считается успехом.

Это проверка настоящих native клиентов через UDP endpoint и локальную имитацию
надёжного carrier. Она не заменяет отдельное интернет-доказательство ICE/DTLS,
не измеряет задержку через NAT и не сертифицирует все игровые режимы/моды.
Сам защищённый транспорт повторно используется из предыдущих поставок.
