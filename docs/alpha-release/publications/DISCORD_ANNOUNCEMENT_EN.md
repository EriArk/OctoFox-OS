# Discord alpha announcements (English)

> Draft Discord announcements. Alpha 7 is public; each message below fits the standard 2,000-character limit.

## Main message — own server

**TrainerOS — the first public alpha is here! 😁**

Well... this got slightly out of hand.

I originally started building a whole system around Pokémon: real party and box data, save-based activities, and things to do outside the game itself.

Then I kept wondering why my other games, friends, and apps couldn't live in the same kind of space. Somehow that turned into TrainerOS. 🤣

**What can you try?**
🎮 Controller-first Linux shell, collections, ROM import, Steam and apps
🤝 One Lobby for supported retro multiplayer, including real handheld tests with PSP, GameCube and classic consoles
💬 Fluxer friends, chats, group calls and a little in-game overlay
🧩 Pokémon save integration and Nearby Link on supported game builds
👤 A customizable 3D character, wardrobe and tiny Home Companion
📦 Crates under Apps: mini-games and widgets
🏘️ Bazaar catalogue previews (worlds and spending are not available yet)

This is **alpha software**, not a promise that every game or network setup will work. That's why I want everyone to try their own games and devices — and tell me what happens, even when it works perfectly.

**Public Alpha 7: compatible ArmadaOS handhelds.** Flip 2 passed installation, first-run QR registration screens, game launch and reboot. Not Android, SteamOS or Bazzite yet.

**Download:** https://github.com/EriArk/TrainerOS/releases/tag/v0.1.0-alpha.7
**Source:** https://github.com/EriArk/TrainerOS
**Support:** https://www.patreon.com/AbyssTail/membership

TrainerOS is free. Testing, bug reports and sharing the project help a lot. Have fun breaking things — just tell me how you did it! 😁
