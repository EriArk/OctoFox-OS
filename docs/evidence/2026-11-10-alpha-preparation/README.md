# Подготовка Alpha без установок — 10 ноября 2026

Владелец остановил установки до возвращения домой и перезагрузки устройств.
Этот проход меняет исходники и готовит пакеты на сервере. К Odin/Flip не
подключались, установленные системы и их настройки не меняли. Появление
устройства в сети само по себе не возобновляет разрешение на установку.

## Исправления

- `artwork_qml_smoke` приведён к текущему входу GameHub → Adapter → Field Guide.
  Встроенные изображения проверяются через реальный Qt image provider, а не
  как отсутствующие локальные файлы. Ожидание конечной анимации зависит от её
  длительности при текущей ширине. Back проверяется как возврат к категориям,
  затем Down возвращает выбранный справочник. Проверки не удалены: явно
  проверяется успешное декодирование каждого изображения.
- Новый Setup проверяет конфликт с ручным launcher **до** создания config,
  ключа и bootstrap. Автоматического присвоения чужих файлов или миграции
  старой ручной установки это не добавляет. Для Odin всё ещё нужен отдельный
  проверяемый переход с резервной копией; такой перенос не является чистой
  приёмкой Flip.
- Упаковщик полного Setup принимает явный HTTPS-контракт каналов через
  `feed_urls` / `--feeds-file`; обязательны ровно alpha/beta/stable. Alpha
  остаётся единственным активным каналом. Новая настройка предназначена для
  сборки Setup, не меняет доверие установленной системы.
- Исправлено затенение параметра `release`: кандидат больше не получает
  релизное имя/README из-за словаря manifest. Ни один режим не выставляет
  `published` или `cleanDeviceAcceptance` автоматически.
- В подготовке обнаружено отсутствие ScreenScraper application identity.
  Использован прежний согласованный доступ приложения из сохранённой копии;
  строгий упаковщик допускает только version/developerId/developerPassword.
  Личные username/password, игры, BIOS и сохранения не включаются.

## Проверки

На временных файловых системах прошли 36 SoftwareInstallation,
7 ReleaseSourceMedia, 16 RuntimeUpstream и 2 ScreenScraperPackaging проверки.
Проверены ранний отказ без записи нового root, оба режима имени/README,
точное сохранение HTTPS feeds и отказ от неверного контракта до создания
пакета. Использованы отдельные тестовые ключи и фикстуры, не портативки.

Серверные QML smoke: Artwork прошёл за 37,06 с, Software Updates за 13,13 с.
Artwork подтвердил 10 форм, реальные изображения, конечный выход/возврат
анимации и фокус; screenshots справочника просмотрены. Updates проверяет
экран/диалоги с фикстурами, не загрузку и применение на устройстве. Прежние
22 ошибки artwork smoke сняты этим повтором; это не измерение скорости Flip.

## Следующий аппаратный проход

После явного возобновления владельцем проверить boot ID, доступность дисков,
I/O и резервные копии. Не выполнять suspend/lid tests или принудительное
восстановление файловой системы. Повторный I/O stall сначала диагностируется.

На Flip прежний оборванный Setup не засчитывать как чистую установку:
сохранить его recovery и личные данные, подготовить чистый согласованный
проход и запустить итоговый Setup один раз через интерфейс. На Odin отдельно
сверить старую ручную установку с rollback и подготовить её явную замену.
Новый Setup заранее отказывает при конфликте, а не выдаёт миграцию за успех.

Затем проверить обычный wizard и сохранённые входы, импорт BIOS/ROM и только
запуск выбранных игр. OTA: первое фоновое уведомление → Updates → download →
подтверждение apply → новый процесс/receipt/first frame → сохранность профиля
и доступность recovery. Multiplayer и посты остаются на потом.
