# Игровая карточка профиля — 2 ноября 2026

## Изменение

[Контракт и композиция](../../PLAYER_PROFILE.md) отражают последние правки владельца:
убрана отдельная строка Player profile, отсутствует View as player, иконки
редактирования/приватности/закрытия находятся возле имени. Имя и действия остаются
над прокруткой. Радиус внешней карточки увеличен до 28; сцена, уровень/XP, Искры,
полка трофеев и журнал образуют единую композицию.

Встроенные источники данных, цены, начисления, приватность, сохранения и геометрия
личной модели не изменены. Общая ProfileScene используется также магазином
и публичным профилем. Новые украшения статичны, без фоновых таймеров и blur.

## Совмещение Companion

База сборки — main `252a2a44`, включая GPU skinning, выгрузку Companion вне
активного Home, запрет Home-only пакетов в Start и маску всей поверхности.
Пакет Crates остаётся 0.1.0: исправления находятся в оболочке/общем Qt SDK.
[Отдельные проверки Companion](../2026-11-02-companion-fixes/README.md) сохраняются
как прежние доказательства; эта работа не выдаёт их за новые измерения на устройствах.
Также включён завершённый `9c8b2221`: подготовка игр и безопасный импорт BIOS-паков.
Все остальные завершённые локальные/remote ветки уже входят в main. Старые
незакоммиченные рабочие копии сохранены отдельно.

## Проверочная среда

Объединённая ARM Release-сборка выполнена на microSD Flip в отдельном каталоге,
с проверкой SHA-256 входящих исходников. UI-сценарии запускаются в контейнере
с изолированными данными, без сети, с offscreen/software renderer. Общий пакет
аватара подключён только для чтения; личные рецепты и базы пользователя не
подключены. Это проверка QML/навигации, не проверка GPU-рендера на экране.

Первый запуск Online остановлен на ожидании отсутствовавшего в контейнере
пакета аватара. После добавления read-only mount сценарий повторён полностью;
проверки гардероба не исключены. Первые логи/кадры сохранены отдельно.

| Проверка | Итог |
|---|---|
| GamePreparationTests, ARM | 27 passed, 0 failed, 0 skipped |
| [Online/profile](online-report.json) | success, diagnostics empty, warnings 0 |
| [Game preparation QML](preparation-check.txt) | PASSED, QML warnings 0 |
| [Home QML](home-check.txt) | diagnostics empty, qmlWarnings 0 |

Online проверяет входы/возвраты, магазин, гардероб, награды, публичные профили,
приватность и контроллерный обход новых иконок без скрытого self-preview.
Подготовка игр проверяет touch picker, фоновый импорт/возврат и обновление списка,
пак, inline Online и Back. Home включает связанное поведение Companion и inbox.
Скриншоты программного рендера используют фикстуры и не подтверждают настоящий
3D-аватар или физический ввод.

## Доставка и ограничения

Позднее в этом же проходе владелец снова разрешил портативки и поручил общую
поставку завершённых работ. В main совмещён `9c8b2221` — подготовка игр/BIOS-паки;
остальные завершённые ветки уже входят в main. Старые незакоммиченные копии
сохранены. Обычная Release-конфигурация пересобирается после UI-проверок.

Общий ARM Release установлен на Flip/Odin, SHA-256
`eb1ba7de119b24672db917dbf515a2da93280069775969d6689b7d0bbaa44b39`.
Проверены запущенные executable, исходные строки базы, неизменность настроек,
пакетов аватара и вспомогательных программ. Odin оставлен на 0%, Flip на 20%.
Прежние бинарники и снимки данных сохранены. На Flip просмотрен настоящий
3D-профиль и Home с округлённым Companion. Найдена пустая подсказка над иконкой:
её исправление и новые движения/шторки `5420614a` следуют в общей поставке.

При ранней подготовке ARM-сборки
обнаружено пересечение общего сборочного каталога с другим чатом. Установленный
бинарный файл не заменялся. Согласованность исходников/генерируемых файлов этого
каталога нужно восстановить до повторного использования; попытка восстановления
не прошла проверку CMakeLists.txt. См. [сборочную заметку](../../ARMADA_PLATFORM.md).

Для текущей сборки используется отдельный каталог; старый общий каталог

исправить подсказку и обновить оба устройства с сохранением данных.
