# Ноябрьское обновление на Odin 2 и Flip 2

На обеих портативках после штатной перезагрузки запущена оболочка Software 54, версия `0.1.0-alpha.8-device.e13484c3`. Путь работающего процесса совпал с подписанной версией, состояние установки — `first-frame-confirmed`. Обновление применили напрямую. Предыдущая сборка осталась доступна для отката.

| На устройстве | Odin 2 | Flip 2 |
| --- | --- | --- |
| Вход в корабль с Home | [Полёт](odin-ship-entry.webp) | [Полёт](flip-ship-entry.webp) |
| После загрузки | [Каюта](odin-ship-cabin.webp) | [Каюта](flip-ship-cabin.webp) |
| Bazaar 0.0.27 | [Площадь](odin-bazaar.webp) | [Площадь](flip-bazaar.webp) |
| Pocket Golf 0.1.25 | [Первый удар](odin-pocket-golf.webp) | [Главное меню](flip-pocket-golf.webp) |
| Micro Rally 0.1.4 | [Выбор кубка](odin-micro-rally.webp) | [Выбор кубка](flip-micro-rally.webp) |

Обе консоли прошли один и тот же цикл. С верхней панели Home открыли корабль, дождались персонажа в каюте и вернулись через Save and exit. На каждой прошло 16 сценариев корабля, включая посадку, перелёт между островами, региональный трафик и станции.

Обе консоли получили подписанный снимок каталога Crates 47, затем дельту 48. Сверены идентификаторы установленных пакетов и контрольные суммы прежних файлов игровых профилей. Пакеты скачивались через тот же сервис установки, который вызывает интерфейс Crates. Три игры запустили в графической сессии на каждом устройстве и штатно закрыли. В локальном Кубке отдельно проверили, что лаунчер передаёт билет текущему бинарному файлу Pocket Golf. Полную сетевую партию между портативками в этот прогон не включали.

Для старых ярлыков Bazaar на обоих устройствах поставили [совместимый лаунчер](../../../tools/bazaar-preview-launch). Он сохраняет параметры личного острова и станции и получает актуальную игру из Crates. Старые клиенты продолжают использовать подписанный каталог v1, ревизию 43.
