# VirtualJaguar и вложенные исходники Setup — 4 ноября 2026

## Что исправлено

Прежний VirtualJaguar сообщал `v3.6.1 f9a3c89-dirty`; неизвестный локальный diff
не удалось восстановить. Вместо присвоения ему чужих исходников собрана новая
ARM64-версия из закреплённого upstream
`f9a3c89f58836cb2c45a42ad4edfac047050f30a`. Единственный локальный patch задаёт
эту метку для исходников без `.git`; эмуляция и формат сохранений не менялись
нашим patch. Это не утверждение об отсутствии различий с прежним dirty binary.

Сборка выполнена без сети в том же изолированном cross-toolchain, что и предыдущие
18 cores. Первая попытка остановилась на некорректном patch; журнал сохранён.
Исправленная попытка `jaguar02` дала core размером **2 375 520 байт**, SHA-256
`5443803109eaee66b542929a5c8fd78c63eb99279a036f2eb8001f1632ee7c7d`.
[Рецепт](../../../packaging/emulators/core-rebuild/jaguar-candidate.json),
[build record](build.json), [кандидат с исходниками](candidate.json).

Повторное продвижение ядер теперь сохраняет записи предыдущих сборок и их
source kits. `component(..., prior_builds=...)` проверяет все уже используемые
build identities; отсутствие, повтор или другой hash/commit отвергаются до
создания output. `media(...)` сохраняет первый kit и добавляет последующие под
именем с SHA-256. Новый компонент меняет только VirtualJaguar; остальные 75 cores
и все 72 `.info` сохраняются побайтно. Записей управляемых замен теперь 19.

`release_source_media.replace(...)` заменяет только
`sources/corresponding-source-app.tar.gz` в проверенном runtime archive и его
inventory entry. Старый архив 605 906 526 байт заменён точным filtered source
`2a6c9c9b` размером 343 808 402 байта; остальной runtime не меняется этим шагом.
Сам исходный архив и прежние runtime generations сохранены.

Setup проверяет **обе** копии application source — внешнюю и вложенную в runtime.
Неправильная ревизия, отдельная геометрия аватара или отсутствующий/повторный
вложенный source entry останавливают сборку до создания каталога Setup.
Отфильтрованный внешний архив больше не скрывает прежний неотфильтрованный внутри.
Это исправление состава исходников, а не готовая incorporated-упаковка runtime art.
Проверка реального sequence 13 также выявила отсутствие Git revision comment у
старого вложенного архива: новый guard отклоняет его уже по этой причине.
[Фактический отказ старого media](old-media-guard.json). Метка обеих новых копий
теперь совпадает с Software; это не попытка объявить старый архив точным `2a6c9c9b`.

  проверили 25 libretro symbols, API и метку `v3.6.1 f9a3c89`.
  [QEMU](abi-qemu.json), [native ABI](abi-native.json).

  создало состояние того же ROM; новый core его загрузил и выполнил 600 кадров.
  Оба процесса завершились с 0. [Новая сборка](native-smoke.json),
  [совместимость тестового состояния](old-state.json).
- Все записи находятся в отдельных тестовых папках. Две личные конфигурации
  RetroArch совпали до/после. Вывод video/audio и физический ввод отключены;
  сообщения `failed_to_start_audio_driver` относятся к этому headless запуску.
  CD/boot BIOS не использовались и Jaguar CD этим тестом не проверен.
- **54 теста Windows и 54 Linux прошли**: ReleaseSourceMedia 5, ReleaseDelivery 10,
  RuntimeUpstream 11, CorePromotion 8, CoreSource 9, CoreRebuild 11.
  Новый тест выполняет два продвижения подряд и проверяет сохранность первого
  source kit/build record; проверки отсутствующих и подменённых записей включены.
- Runtime и Core Sources полностью перечитаны после сборки. Source inputs
  собраны для 76/76 cores нового компонента. Неизвестный dirty diff больше не
  требуется для **нового** VirtualJaguar; прежний бинарник не объявлен восстановленным.

## Установка на Flip

**Runtime 13 → 14 установлен через обычный GUI Setup.** Использованы точный
bootstrap из проверенного полного Setup, подписанный runtime archive и уже
имеющийся подписанный Software через `--offline`. Полный tar на Flip повторно
не копировался. Это обновление существующей установки, не повторная чистая
установка с нуля. Из TrainerOS вышли через Start → Switch → Desktop → Continue;
системные этапы прошли через обычные диалоги Armada. Файлы блокировок вручную не удалялись.

- Software и runtime audit — `ready`; все 76 установленных core hashes совпали
  с новым binding. Транзакций, требующих восстановления, нет.
- 31 контрольный файл профиля/настроек/баз совпал со срезом после штатного выхода
  из оболочки и до обновления. Это не полное хеширование личной ROM-библиотеки.
  Игры, BIOS и пользовательские сохранения не добавлялись в пакет и не удалялись.
- Предыдущий runtime 13 и его Software pairing сохранены; проверены recovery
  blobs всех 19 прежних cores. Фактический откат 14 → 13 не выполнялся.
- Установленный VirtualJaguar выполнил ещё один изолированный запуск
  `pattern_fill.jag` на 600 кадров и записал тестовое состояние, exit 0.
  Личные конфигурации RetroArch остались прежними. Вывод/физический ввод отключён.
- Через установленный Return to TrainerOS вернулись в отдельную Gamescope
  сессию. Home визуально подтверждён, Mika и баланс сохранились; health стал
  `first-frame-confirmed`. Plasma и тестовый RetroArch завершены.

[Проверка установленного набора](installed.json), [установленный core](installed-smoke.json),
[возврат Home](session.json). Свободно **12,02 GiB** внутреннего раздела после
обновления; большие входные архивы и тестовые файлы оставлены на microSD/сервере.
Odin не использовался. Проверки физических кнопок, звука и разных сетей не
выдаются за выполненные; публичного release/OTA этим обновлением не создано.

## Оставшаяся работа

Упаковка `assets/avatar` и файлов кеша работающей оболочки ещё не изменена.
Сейчас AvatarAssets создаёт GLB, который используют общий AvatarScene, гардероб
и SDK `avatar.resolve`; только переименование/архивация исходников не меняет
эту цепочку. Следующий шаг — согласованный reader/pack/cache без потери выбранных
образов и совместимости потребителей. Оригиналы сохраняются отдельно.

Остаются внешние source/build dependencies и notices для фактических Flatpak,
AppImage и native Python wheels, а также точный Eden input. Публичная подпись,
GitHub release/assets и OTA feed ещё не опубликованы. `redistributionReviewed`
не выставлен. Ни полная игровая приёмка Jaguar, ни сеть/звук/физические контроллеры
этим проходом не сертифицированы; они не превращены в новый gate альфы.
