# Установщик с закреплёнными upstream-пакетами — 4 ноября 2026

Следующий комплект готовится по согласованной схеме: Setup сам получает точные
оригинальные пакеты, затем устанавливает и настраивает их в private runtime-home.
Существующие EmuDeck/Flatpak и пользовательские настройки не используются как
исходники установки. Этот вариант требует интернет во время установки.

## Состав и сохранённые версии

- ARMSX2, Azahar, melonDS, RPCS3 и Eden найдены в оригинальных источниках с **теми же
  SHA-256**, что у проверенного runtime 16. DuckStation сохраняет ранее реализованный
  прямой download. Asset ID/URL, размер и hash закреплены в подписанном media.
- Cemu заменяется отдельно: прежний moving-nightly asset недоступен. Проверенная
  стабильная 2.6-4 прошла первый мастер, открыла [главное окно](cemu-stable.png) и
  штатно завершилась с кодом 0 на Flip в отдельном тестовом HOME. Новая nightly
  a53cf0ece упала после мастера и **не включена**. Запуск игр Cemu этим не подтверждён.
  Замена требует совпадения прежних bytes/hash; произвольный latest не допускается.
- [10 оригинальных Flathub commits](flathub-original.json) скачаны с проверкой
  GPG-подписей и закреплённого commit, экспортированы в локальные bundles. Только
  после подготовки используется прежняя транзакция установки/отката. Приватный
  staging не меняет пользовательские remotes/refs. Подменённый cache не принимается.
- Точный старый Dolphin commit upstream вернул 404. Он **остаётся bundled** вместе
  с модифицированным PPSSPP; исходники/рецепты сохранены. Другую версию Dolphin
  установщик автоматически не выбирает.
- Vita3K build 4168 найден в официальном архиве Vita3K-builds. Setup читает SquashFS
  как данные, сверяет каждый файл, сохраняет наши launcher/transport и исправленный
  AppRun.wrapped. [Все 319 итоговых файлов совпали](vita-original.json) с прежним
  компонентом. Это не обновление Vita и не новая проверка его игрового мультиплеера.
- Длительные Flathub download/export каждые 10 секунд показывают этап и прошедшее
  время. Timeout и отмена остаются ограниченными; скрытого второго Setup нет.

## Проверки и граница готовности

Linux: RuntimeUpstream 14, RuntimeFlathub 5, RuntimeVitaUpstream 4,
RuntimeInstallation 24, RuntimePayload 8, RuntimeEnvironmentRecovery 3 прошли.
SoftwareInstallation: 31 тест прошёл в контейнере, один требовал LICENSE и visudo;
после исправления тестового окружения этот тест прошёл на Linux-хосте. Код
продукта ради этих ошибок окружения не менялся. Новые Vita-проверки также прошли
на Windows. Реальные downloads/export выше выполнены отдельно от unit fixtures.

Чистый проход Software 9/runtime 16 по-прежнему действителен только для того
[кандидата](../2026-11-04-installer-final/README.md). Новый комплект ещё нужно
подписать и пройти на Flip целиком: один Setup → первый запуск → игра → reboot.
Публичный GitHub release/OTA ещё не опубликован. Установленный TrainerOS сохранён;
Cemu проверялся изолированно, Odin не менялся.

## Очередь до выпуска

1. Финальная сборка с точными исходниками и материалами bundled-компонентов.
2. Новый чистый проход на Flip, без ручного ремонта и повторного Setup.
3. GitHub assets, проверка публичной загрузки и preview OTA.

Сбор прежних Flatpak source inputs также закончен: 1670 архивов исходников и
459 Git-входов; проприетарный NVIDIA Cg для другой архитектуры не включается.
Из GStreamer исключён только отдельный необязательный корпус тестового видео,
не исходники программы. Эти материалы не подменяют новые проверки установки.
