# Кубические существа — художественный образец v1

3 ноября 2026. [Требование #161](https://github.com/EriArk/TrainerOS/issues/161).
Образец подготовлен по продолжению владельца после доставки Emerald `28f7199b`.
Это **предложение стиля**, не одобренный набор и не выполненный встроенный fallback.

## Посмотреть

- [Интерактивный просмотр размеров и кадров](preview.html): открыть локальный HTML
  рядом с PNG. Нет внешних зависимостей, сети, учётной записи или загрузки файлов.

Небольшой жёлтый куб, широкий зелёный блок, высокий оранжевый, летающий сиреневый

Названия в preview описывают силуэт, а не переименовывают виды.
Ни один рисунок пока не привязан к species/form ID.

## Что проверено и что не готово

Концепт просмотрен в рамках **32, 48, 96, 160 CSS px**. Уменьшение выполняет
браузер из больших фрагментов, а не нарисованный генератором нижний ряд.
Цвет и силуэт различимы на 32 px; выражение глаз и мелкие выступы лучше читаются
от 48 px. Для отдельных игровых иконок нужно более плотное кадрирование и
проверка на настоящем фоне: концепт содержит непрозрачную кремовую подложку.

`idle-study.png` — отдельная четырёхкадровая проба нейтрального существа.
RGBA-прозрачность подтверждена; фактический размер 2172×724, четыре столбца по
543 px. Preview использует одинаковую область 424×424 внутри каждого кадра
и показывает её в 32/64/128 px на светлом и тёмном фоне. Доступны запуск,
остановка, покадровое сравнение; при скрытии страницы цикл останавливается.

**Анимационная проба не принята для поставки.** Первая генерация имела явную
цветную кайму; редактирование уменьшило её, но не устранило полностью. Между
кадрами есть небольшое изменение контура. Генерацию нельзя считать готовым
выровненным атласом. Встроенные providers не используют эти файлы.

Отрисовка выполнена локальным Edge в отдельном headless-профиле. Основной
встроенный браузер достиг лимита окон; чужие окна не закрывались. Просмотрены
светлое/тёмное окружение, открытые/закрытые глаза и последовательность пробы.
Ни приложение, ни портативки в этом проходе не изменялись.

## Происхождение и границы распространения

Оба PNG созданы встроенным `image_gen` из записанных текстовых промптов.
Концепт создан без изображений-референсов; проба использует этот концепт,
затем собственный предыдущий результат как источник правки. Официальный арт,
ROM, извлечённые спрайты и частные пользовательские packs не использованы.
Оригиналы сохранены; в этой папке — их копии без пиксельной обработки.
HTML только кадрирует и масштабирует их для просмотра.

Файлы включены как материалы обсуждения, **не как разрешённые release-ассеты**.
Условия распространения будущего встроенного набора и индивидуальная проверка
под #116 ещё не завершены. Программная GPL-лицензия проекта сама по себе не
лицензирует эти изображения: действует раздел artwork в LICENSING.md.
Происхождение из генератора не означает прохождения проверки.

## Следующий предлагаемый шаг

После обратной связи по стилю сделать один воспроизводимый эталон существа:
единая геометрия/камера, чистая альфа, фиксированный размер и baseline всех
кадров. Проверить портрет, Idle, WalkLeft/WalkRight, Sleep и фактические нужды
Playroom/Link; не придумывать отсутствующие состояния и не растягивать Idle
на все действия. Только затем расширять покрытие и включать fallback в
существующие providers с независимым приоритетом пользовательских art/sprites.
Настоящие имена, формы, параметры и сохранения остаются без изменений.
