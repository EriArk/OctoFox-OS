# Home свёрнутой игры, шапка и нижняя панель — 2 ноября 2026

Запрос владельца: уровень после имени; Home при свёрнутой игре должен сразу
показывать то же меню, что во время игры, без дополнительного перехода в Game Options.

`ShellController::dispatch(Home)` при живой игре вызывает существующий
`liveGameRequested(true)`. Composition передаёт запрос в
`AdventureOverlayService::returnToGame(true)`: действующий helper возвращает
фокус тому же игровому процессу, ждёт нейтрального ввода и открывает привычный
`GameOptions`/`GameActivity`. Continue выбран первым. Промежуточный `ShellOptions`
не создаётся, маршрут оболочки сохраняется. Без игры Home работает как прежде.
Отказ готовности helper показывается явно; сбой передачи управления сохраняет
существующий возврат в оболочку. Защищённое завершение игры не изменено.

Looks перенесён в общий игровой список: действие использует обычное сворачивание,
затем существующий профиль/гардероб. Оно не создаёт вторую игровую сессию.
Уровень стоит сразу после имени, Искры под именем. Промежуточная крупная колонка
отменена; используется существующий шрифт оболочки, без дополнительных ресурсов.
Отступы колокольчика и граница поповера сохранены.

Нижняя панель: подсказки слева, сеть / батарея / часы справа; часы у правого края. Подсказки
подстраиваются под доступную ширину. Часы обновляют время локально; состояние
сети поступает через `QNetworkInformation` от системного backend, без запуска
сканирования Wi-Fi. Неизвестное состояние обозначается явно; подключение к сети
не является доказательством доступа к произвольному интернет-сервису.

Нажатие Wi-Fi открывает общий `ConnectionsPopup` над иконкой, без Start.
Start использует тот же компонент по центру своей панели. Список сетей,
пароль, сохранённые сети, ошибки и повтор подключения остаются в существующем
`NetworkController` / `ConnectionsPane`. Поповер удерживает ввод, Back возвращает
в исходный экран; повторный тап и тап снаружи закрывают его. Поиск сетей активен
только во время открытого интерфейса подключения, как и раньше.

Ушки используют общий `Theme.buttonLabel` и обновляются при смене профиля
контроллера. Quick Apps соответствует северной кнопке, Recent — западной:
PlayStation △ / □, Xbox Y / X, Nintendo X / Y. Круглые подложки удалены,
сенсорная область и действия сохранены.
Без распознанного типа геймпада ушки показывают действующие клавиатурные
клавиши X / Y вместо прежних стрелок, обозначавших положение кнопок.
