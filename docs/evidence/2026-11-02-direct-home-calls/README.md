# Прямой Home, звонки и два колокольчика — 2 ноября 2026

Основной поток установлен на Flip/Odin. Последняя поправка оформления toast
готовится к повторной поставке после отклонения жёлтого варианта владельцем.
Исходная база `b44f1a2d`, включая подготовку DS `2d3152c5`.
Новые DS runtime-пакеты не устанавливаются этим проходом.

## Контракт

- Home без игры → главный экран, повторное Home ничего не открывает.
- Живая/свёрнутая игра → существующее игровое меню, без промежуточного Now.
- Верхний колокольчик → inbox под собой; нижний после часов → inbox над собой.
  Содержимое и выбранная запись общие. Вторая иконка перемещает открытый inbox.
- Обычные уведомления и входящие звонки → справа снизу над нижней строкой.
- Ответить/Отклонить доступны прямо в звонке и inbox. Нажатие тела плашки
  не отвечает автоматически. Смахивание или Back только скрывает всплывашку.
- Скрытая всплывашка не появляется снова при повторном snapshot/переподключении.
  Подтверждённое окончание звонка разрешает новую всплывашку того же собеседника.
  Другая учётная запись не наследует скрытие; устаревший ID не отвечает на другой звонок.
