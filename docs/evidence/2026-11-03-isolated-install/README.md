## Исправление обновления bootstrap

Production `1a184065` собран, но запуск полного кандидата 04 остановился до
установки: bootstrap отличался от установленного и прежний guard запрещал любое
такое обновление. Установка 03 и её данные остались целы. Теперь только явный
Setup-проход может заменить bootstrap, после отдельного диалога, проверки прежнего
инвентаря и runtime/transaction locks. Linux renameat2 EXCHANGE оставляет по
рабочему пути целое старое либо новое дерево. Старое дерево сохраняется вместе с
инвентарём, journal переживает прерывание; launcher нового дерева требует закончить
операцию. OTA автоматически bootstrap не заменяет, ключ доверия не меняется.
[39 Linux-проверок](bootstrap-update-tests.log) прошли. Исправленный полный кандидат
готовится к повторному GUI обновлению; отказ 04 не засчитан как успешное обновление.
