# AppImage: происхождение Cemu/ARMSX2 и условия DuckStation

3 ноября 2026. Проверены **байты пакетов автономного кандидата**, без запуска
эмуляторов и без обращения к пользовательским играм/сохранениям.
[Опись](identities.json) содержит SHA-256 AppImage и ELF, смещения найденных строк,
точные upstream commits и ссылки/хеши лицензионных материалов.
[Скрипт проверки](inspect.py) выполняет чтение, а не запуск ELF.

## Cemu

В `shared/bin/cemu` обнаружена строка `Cemu cee557d`. Она соответствует
[`cee557d46d63e3407dc3bbda6480c0c674e8bb80`](https://github.com/cemu-project/Cemu/commit/cee557d46d63e3407dc3bbda6480c0c674e8bb80).
Именно эта версия [version.h](https://github.com/cemu-project/Cemu/blob/cee557d46d63e3407dc3bbda6480c0c674e8bb80/src/Common/version.h)
составляет имя из Git hash; CMake получает его через `git log --format=%h -1`.
Это новая проверка бинарника, а не перенос старой строки из игрового журнала.
Прежнее утверждение о неизвестной встроенной ревизии Flip заменено этим результатом.

[Исходники собраны](cemu-source.json): 33 193 211 байт, 16 662 файла,
10 Git-деревьев. Основная лицензия этой ревизии — MPL-2.0; сторонние условия
сохранены внутри архива. Установленный AppImage не заменялся.

В ELF также имеется путь сборки `Cemu-AppImage-Enhanced`. Исторический
[recipe упаковщика](https://github.com/pkgforge-dev/Cemu-AppImage-Enhanced/blob/e91f83043b84bfcfcf4c2d92ec763b5884c4fed7/get-dependencies.sh)
собирает официальный Cemu, но использует rolling pacman/AUR и shallow HEAD.
Дата recipe и строка Git **не доказывают** его точное соответствие данному build,
отсутствие локальных патчей или состав всех встроенных библиотек. Этот пробел
остаётся; архив upstream не объявлен полной воспроизводимой поставкой AppImage.

## DuckStation: решение для публичного комплекта ещё не принято

Полный commit из нашего ELF —
[`dd4a0eb779296a525f8b10b6d9a45911ad6d088f`](https://github.com/stenzek/duckstation/commit/dd4a0eb779296a525f8b10b6d9a45911ad6d088f).
Проверен [LICENSE именно этой версии](https://github.com/stenzek/duckstation/blob/dd4a0eb779296a525f8b10b6d9a45911ad6d088f/LICENSE):
**CC-BY-NC-ND-4.0**. Это не GPL-компонент.
[README той же версии](https://github.com/stenzek/duckstation/blob/dd4a0eb779296a525f8b10b6d9a45911ad6d088f/README.md#downloading-and-running)
допускает передачу неизменённых релизов при условиях лицензии и отдельно относит
преднастроенные настройки/пакеты к модификациям. Простое сохранение исходных байтов
AppImage поэтому не считается достаточным разрешением нашего настроенного набора.

Конкретные варианты для владельца:

- Оставить DuckStation отдельно подключаемым: сохранить обычный запуск внешней
  установки и ссылку на официальный ресурс, не включать его в публичный полный
  архив. PS1 сохраняется через уже поставляемый PCSX-ReARMed. Текущие частные
  установки, карточки памяти и профили не удаляются. Изменение состава публичного
  runtime и совместимость со старыми поколениями потребуют отдельной реализации.
- Сохранить DuckStation внутри полного настроенного комплекта после получения
  отдельного разрешения на этот сценарий. До этого не публиковать данный компонент.
  Письмо автору без поручения владельца не отправляется.

Это предложение выбора, **не принятое исключение платформы/эмулятора**. Ни наличие
Patreon, ни бесплатная загрузка сами по себе здесь не объявлены окончательным
юридическим ответом; для нашего сценария разрешение пока не подтверждено.

assets/feed и новой игровой/физической/сетевой приёмки нет.
