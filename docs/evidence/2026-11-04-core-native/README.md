# Кандидаты cores на Flip и исправление AppleWin — 4 ноября 2026

## Результат

Проверен **настоящий private Flatpak RetroArch на Flip**, а не только QEMU.
18/18 выбранных ARM64 библиотек загрузились через ABI probe; у 10 разных ядер
дополнительно выполнен запуск машины, игры или upstream demo. Это ограниченный
smoke для альфы, не приёмка всех игр, контроллеров, звука или интернет-мультиплеера.
Точный RetroArch: `1.22.2`, Git `69a4f0ea1e`, Flatpak commit
`a72a8a0a7cde5c24a0134a32fdc1469fb644c459e9974f644e95170ae5dba8bc`.

Рабочий runtime **не заменён**: все 18 прежних core hashes и обе личные конфигурации
совпали с baseline. Личные ROM/BIOS использовались только для ограниченных проверок;
копии нужного BIOS, состояния, SRAM, options и playlists находились в отдельном
каталоге. Процессы тестового RetroArch завершены, оболочка продолжает работать.
[Итог сохранности](preservation.json). Odin не использовался.

## Исправленная причина отказа

AppleWin успешно проходил `dlopen`, но реальный `retro_load_game` выбрасывал
исключение при `canonical()` отсутствующего каталога исходной сборки рядом с
исполняемым RetroArch. До предусмотренного upstream fallback дело не доходило.
[Ошибка до исправления](applewin-before.log).

Один небольшой [патч](../../../packaging/emulators/core-rebuild/patches/applewin-relocatable-resources.patch)
переводит поиск необязательных debug/printer resources на non-throwing overload;
существующий fallback сохранён. Embedded firmware и эмуляция не менялись.
Патч привязан к исходному commit и своему SHA-256. Сборщик проверяет его до
распаковки/сборки, записывает с новым бинарником; пакетировщик не позволяет выдать
старый непатченный файл за результат нового рецепта. Изменённые и отсутствующие
патчи отвергаются. **11 тестов Windows и 11 Linux прошли**, включая четыре новых
защиты. [Linux](linux-tests.txt), [build record](applewin-build.json).

Новая попытка `attempt08`: SHA-256
`f1330e1e74614e3c9ddd9710484133507fcd9106ca9e17ed87f223ea18380890`,
3 979 416 байт. Прошли QEMU ABI, native ABI, 600 кадров без экрана и 300 кадров
с Vulkan/Turnip Adreno 650 внутри отдельного Gamescope `headless`.
Кадр Apple //e просмотрен локально; это вывод BIOS, не прохождение игры.
[После исправления](applewin-after.log), [GPU log](applewin-gpu.log).
Прежний кандидат и исходный установленный бинарник сохранены.

### Состояния и netplay PC Engine

В отдельной папке старое ядро создало состояние Reflectron; новое успешно
загрузило его и продолжило выполнение. Тестовый SRAM 2048 байт остался побайтно
тем же. Это не миграция личного прогресса и не доказательство совместимости
всех старых состояний. [Точные hashes и сообщения](save-compatibility.json).

Два процесса RetroArch в **одном изолированном network namespace на Flip**:
новое/новое и новое/прежнее ядро. В обоих случаях состоялось соединение,
назначены player 1/2, выполнен лимит 30 000 кадров при `--check-frames=60`,
нет сообщений о рассинхронизации, оба процесса завершились с кодом 0.
Это около 14 секунд ускоренного выполнения на пару, а не восемь минут
реального пользовательского сеанса. [Одинаковые cores](netplay-same.json),
[разные сборки](netplay-mixed.json). Проверены только loopback и указанный ROM;
не проверены приглашение Lobby, два физических игрока, LAN, NAT или Интернет.
Существующие правила допуска/защиты сохранений TrainerOS не менялись.

### Что осталось экспериментальным

Для `amiarcadia`, `arduous`, `minivmac`, `pokemini`, `same_cdi`, `uzem`, `x1`
подходящего контента в доступной библиотеке этого прохода не оказалось:
подтверждён только native ABI. Gearcoleco без картриджа выбирает ADAM и требует
EOS/SmartWriter BIOS; их не было в выбранном наборе. Core корректно отказал
с явным перечислением файлов. Это не доказательство поломки картриджного
ColecoVision и не повод подделывать BIOS. [Отказ](gearcoleco-missing-firmware.log).

Эти восемь маршрутов остаются непроверенными для игр. Глубокая проверка
каждого из них не объявляется новым alpha blocker: сохраняются прозрачные
экспериментальные пометки и задача тестерам. Физический input/audio отдельно.
