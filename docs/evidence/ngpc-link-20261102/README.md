**Объединение с другим чатом:** первоначальная production-сборка `371883e7…`
на базе `d4ca1071` не была установлена. Защита обнаружила новую оболочку

Реализован `runtime.ngpc.link.v1`: обычное лобби, два места, готовый NgpCraft
mirror и существующий кабинетный ICE/DTLS transport. [Контракт, сохранения,
обновление и откат](../../emulators/neogeo-multiplayer.md#связка-ngpc-с-lobby--2-ноября-2026).

## Проверки

- Python: 9 проверок framing, раздробленных записей, отказов, RTC,
  повреждённых/чужих saves, атомарной замены и внешнего изменения файла.
- Четыре native машины на ARM64 и реальном ICE/DTLS: 300 кадров с разными
  нажатиями и разным собственным flash/RTC; зеркальная память совпала,
  каждая сторона получила кнопки соперника. 3,166 с headless, не игровой FPS.
- Два настоящих Python/SDL launcher-процесса: старт, повторное открытие собственных
  данных, TERM; отдельный обрыв транспортов оставил окна открытыми и исходные
  checkpoints неизменными. SDL dummy проверяет код рендера/аудио, не экран или звук.
- Проверки выполняются в отдельном container network namespace на Flip.
  Первоначально namespace без адреса не дал ICE candidates; используется обычная
  частная сеть контейнера. Это не separate-WAN acceptance.

- 27 OverlayHelper checks; 18 CartridgeContent QtTest, включая сырые/архивные
  NGP/NGPC; 3 результата focused Standalone на настоящем sealed bundle; 106
  RuntimeMultiplayer и 4 focused Lobby результата без ошибок/пропусков.
- SDL virtual pad: нажатия, нейтрализация при потере фокуса, hotplug, quit;
  реальный X11 frontend на Flip: window/process ownership, нормальное закрытие
  через WM_DELETE_WINDOW и запись собственного состояния. Потеря связи оставила
  читаемую [карточку отказа](link-disconnected.png); закрытие также штатное.
  Для визуального probe использован свободный upstream ROM, не retail-матч.
- Native/Python/Lobby проверки сделаны до объединения с `51140203`; этот commit
  меняет каталог/хранилище/интерфейс, сохраняя код NGPC и его транспорта.
  Повторная production-сборка проверяет совместимость объединённых исходников.

## Поставка

Общая production-сборка на базе `51140203` установлена и запущена на **Flip/Odin**:
`5110839cdf20e420d6f441eb3636e70e7a45547d5c0c1a21a150a1df6b9c675e`. BUILD_TESTING=OFF, avatar preview включён; UI-test mode отсутствует.
Сверены все 1318 входных файлов и sealed bundle; [точные хеши и результаты](build.json).
Сборка и контейнеры находились на microSD Flip; резервные копии оболочки,
настроек и согласованные SQLite snapshots — во внутреннем recovery каждой
портативки. Изменены только оболочка, отдельный NGPC-пакет и общий overlay helper.
Odin получил также прежние распознаватели Model 3/Odamex, отсутствовавшие в его helper;
уникальных изменений другого чата там не было.

На обеих проверены точный hash живого процесса, startup window, отсутствие
QML startup errors, загрузка native библиотек и hashes всех файлов пакета.
Прежние записи профилей/игр/сохранений/истории, настройки, остальные runtime
manifests, обычная RetroArch integration и avatar pack сохранены; громкость
Flip 20%, Odin 0%. [Результаты поставки](delivery.json). Odin использован только
для установки и короткой проверки запуска, без нагрузочной проверки карты.
Прохождение retail-игры или полный пользовательский путь через Lobby этим не заявлены.

## Оставшиеся границы

Широкая игровая совместимость/HLE, разные внешние сети и другая архитектура
не объявлены проверенными. Отдельный linked progress не равен миграции solo saves.
Список игр доступен по установленному runtime и формату, без списка тестированных
названий. Общая запись R049 остаётся частичной по своим оставшимся условиям.
