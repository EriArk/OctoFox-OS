# Доставка большого Setup и исходные материалы — 3 ноября 2026

## Результат

Подготовлена загрузка полного Setup частями с GitHub Releases: маленький Download
kit закрепляет SHA-256 описи; каждая часть и собранный архив проверяются. После
распаковки открывается обычный Setup с прежней проверкой подписей и Recovery.
Обрыв загрузки сохраняет части, повторный запуск проверяет уже собранный архив
и распакованные файлы. Изменённая папка не перезаписывается. При отмене сборки
временный файл удаляется, проверенные части сохраняются. Архивы не опубликованы.

Один asset GitHub должен быть меньше 2 GiB; поэтому полный архив разбит на части
по 1 GiB, последняя меньше. Это транспорт того же пакета, не новый OTA-протокол
и не замена подписей Software/runtime. [Официальный лимит GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).
Tag `v0.1.0-prebeta.1` в описи — будущий адрес кандидата, не существующая публикация.

## Проверки и ограничения

[88 Linux-проверок](linux-checks.log), включая 10 новых проверок транспорта/исходников:
докачка HTTP Range, повреждённая часть/общий хеш, подмена описи, порядок/размеры,
отмена, сохранение существующих файлов, опасные пути/ссылки, полный bootstrap kit,
неизменность исходного архива и правильная ревизия. Эти 10 проходят также на Windows.
Первый большой прогон выявил запрет пробела в имени `Install TrainerOS.sh`:
исправлен только обработчик путей Setup, добавлен такой файл в regression fixture.
Повторный прогон использует сохранённые и заново проверенные части.

`publisher.py` теперь отвергает source archive другой ревизии либо с отдельной
геометрией аватара. `.gitattributes` исключает такую геометрию из будущих Git
source exports; оригиналы в рабочем дереве/истории и внешний вид не меняются.
Это **не** завершение лицензирования runtime pack: модели пока поставляются
отдельными GLB и генерируются в кеш. Требование incorporated use и остальные
условия CGTrader остаются в работе. [Условия](https://www.cgtrader.com/pages/terms-and-conditions).

Остались exact-source/build материалы готовых libretro cores, Flatpak/platform
зависимостей, части AppImage и native-библиотек Python wheels. У Eden найден
embedded `da42070c4ad25840c9ee25344bde9d0a8584f5a9`; доступный tag 0.2.1 указывает
на другую ревизию, поэтому он не подставлен вместо нужной. Архив его точной версии
ещё не собран. Подробная [очередь исходного комплекта](../../RELEASE_SOURCE_BUNDLE_RU.md).

Ни source/license review, ни публичный release/OTA feed не объявлены готовыми.
Flip/Odin в этом проходе не менялись; прежние результаты установки сохраняются.
Недостающие функции мультиплеера не превращаются в условие выпуска альфы.
