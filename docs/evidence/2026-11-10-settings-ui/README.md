# Settings: спокойный интерфейс — 10 ноября 2026

По запросу владельца переработаны System/Updates и общие экраны Settings.
Работа ведётся без установки на Odin/Flip. Это изменение оболочки и её
представления существующих команд; владельцы обновлений, сети, профилей,
хранилища и ввода не заменяются.

## Поведение

- Общие настройки используют плоские строки, спокойный фон выделения и тонкие
  разделители. Высота обычной строки зависит от текста; пояснения переносятся.
  У ползунков видны процент, недоступность или выключенный звук. Плюс/минус
  имеют отдельные сенсорные зоны. Длинные списки показывают полосу прокрутки.
- System начинается с Software updates, затем показывает сведения устройства,
  обновление статуса, диагностику и питание. Порядок джойстика соответствует
  экрану; возврат из Updates сохраняет выделение этого пункта.
- Updates показывает установленную версию, доступную версию, состояние,
  прогресс и последнее время проверки. Одно основное действие соответствует
  состоянию: проверить, скачать, приостановить/продолжить или применить.
  Канал и фоновая проверка находятся ниже; загрузки и описание выпуска рядом.
  Alpha доступна, Beta/Stable зарезервированы. Обновления хоста не заявляются
  подключёнными; обновления приложений остаются в Apps → Crates.
- Предыдущая версия, repair, проверка файлов и очистка кеша находятся в
  Recovery & maintenance. Apply/rollback/repair открывают отдельное
  подтверждение с начальным фокусом Cancel. Back возвращает к исходному
  действию; другие команды и переключение страниц не обходят подтверждение.
  Проверка безопасности перезапуска существующим владельцем сохранена.
- Исправлены расстояния между временем, датой, подписью и строками Clock.
  Controller и Tools прокручиваются за фокусом; калибровка и сброс не являются
  мелкими текстовыми ссылками. В сетевых строках Settings убраны декоративные
  цветные круги, вкладка Wi-Fi/Bluetooth имеет явное выделение. Credits
  прокручивается; Game storage использует плоское представление.

## Проверка и границы

Release x86 собрана в существующей изолированной серверной среде.
`software_update` прошёл за 33,53 с, включая защиту подтверждения и порядок
доступных действий. `interactions` прошёл за 0,99 с. Сценарий Settings
проверяет 18 страниц при 960×540 в Light/Dark, дополнительные состояния
контроллера, игровых раскладок, входа, Wi-Fi и 1920×1080. Updates проверяет
check/download/pause/resume, общие Downloads, notes, подготовку, подтверждение
с Cancel, запрет смены страницы и посторонней команды, error, Recovery и Dark.
Итоговый `settings_qml_smoke` прошёл за 40,44 с, `software_update_qml_smoke`
за 12,38 с, без QML warnings. Фактические снимки просмотрены; это не макет.

При визуальной проверке выявлены следы Shape-иконок предыдущей страницы
в software renderer. Settings в этом режиме компонуется отдельным непрозрачным
слоем с размером текстуры по UI scale; повторные снимки чистые. Hardware
renderer дополнительный слой не включает. Это исправление отрисовки,
не измерение производительности Flip. Проверки с фикстурами и виртуальным SDL-контроллером
не являются приёмкой физических кнопок, реального OTA или скорости Flip.
Публичный выпуск и установки в этом проходе не выполняются.
