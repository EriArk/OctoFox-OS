## Реальный комплект

Используется ранее проверенный архив компонентов `ef32232b…`, 29 компонентов,
12 Flatpak refs и 38 wheels. Для проверки создан отдельный временный ключ;
production-ключ не копировался и не заменялся. Software и runtime envelope
проверяются одним lab public key. Сеть контейнера выключена.

Реальный проход завершил подготовку, намеренное прерывание после файлов,
продолжение, повтор, следующее поколение, откат и удаление. Личные тестовые данные
и исходный код восстановлены; итог записан в [offline-cycle.json](offline-cycle.json).
Системный helper работал в отдельном тестовом rootfs:
это проверка его файлового журнала, не реального окна pkexec или переключения сессии.

## Не считать пройденным

Чистая привилегированная установка на загрузочной системе, реальная смена
Desktop/TrainerOS, запуск эмуляторов, физическое управление/голос, отдельные сети,
полный source/licence inventory всех runtime, production-подпись/публикация и
загрузочный образ остаются открытыми. Flatpak внутри контейнера имеет известное
ограничение nested bubblewrap; совпадение refs не доказывает запуск приложений.
