# Adapter navigation stickers

Nine original transparent PNG illustrations generated with the built-in OpenAI
`image_gen` tool on 14 November 2026 at the owner's request. No reference images,
game assets, logos or third-party character designs were supplied. The creatures
are original decorative illustrations, not portraits of owned game entities.

Exact inputs: [prompts.json](prompts.json). File sizes and SHA-256 identities:
[manifest.json](manifest.json). Originals are preserved; the native image loader
decodes them at a bounded presentation size. Alpha transparency is retained.

The Pokemon module owns their screen mapping; the host accepts an optional art
URL from any trusted adapter and retains a generic icon fallback. Labels are native
text outside the art. These images do not enable transfers, shops or save writes.
Bundled under the repository asset terms, consistent with the generated Bazaar art.

The approved set is party, boxes, dex, center, shops, playroom, profile, journey
and hall. See [the interface contract](../../../../docs/ADAPTER_HOME.md).
