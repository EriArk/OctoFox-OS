## Решение о публикации

- **GO** — все обязательные для заявленных платформ gate закрыты; допустимые ограничения прямо раскрыты.
- **LIMITED GO** — выпускаем как экспериментальную альфу для узкой проверенной конфигурации, без обещаний вне неё и без критических рисков сохранности данных.
- **NO GO** — есть риск потери данных, недостоверный пакет/источники, провал обязательного пути установки либо другое критическое препятствие.

Решение принимать **по конкретному кандидату и целевой конфигурации**, а не по общему ощущению готовности проекта.
