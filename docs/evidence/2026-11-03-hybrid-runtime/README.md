## Реализация

`runtime_upstream.py` получает только проверенный source/числовой asset ID. Descriptor
находится внутри подписанного runtime media. Размер/хеш неизменны; не запрашивается
новейший release и не исполняется чужой installer/script. Старый runtime до завершения
подготовки не меняется; partial download сохраняется для продолжения.

`upstream_media.py` преобразует проверенное автономное media, только если официальный
asset совпадает с выбранной сборкой. Старый оригинал сохраняется. `offline_setup.py`
помечает новый Setup как hybrid и сообщает о нужном интернете; всё остальное
остаётся в существующем install/rollback journal. Конфигурация генерируется нашим
кодом в private runtime-home/частном сеансе, не поставляется как изменённый DuckStation.

```sh
python3 packaging/software/upstream_media.py TrainerOS-Full-CANDIDATE.tar \
  --plan packaging/emulators/upstream-arm64.json --output TrainerOS-Hybrid-Runtimes-CANDIDATE.tar
```

Runtime media передан `offline_setup.py --archive` вместе с `--runtime-manifest`:
предварительно подписанная опись сверяется по sequence, Software source, полному
списку файлов и хешу/размеру архива. Это позволяет собрать большой Setup на сервере,
не переносить закрытый ключ и не занимать ещё 4 ГБ на почти заполненной microSD.
Полный Setup собран и независимо проверен; публичного GitHub release нет.

## Доставка на Flip — последующий проход 3 ноября

Hybrid runtime sequence 12 активирован обычным GUI Setup, с подтверждением polkit.
Bootstrap взят из проверенного полного кандидата 09: 72 файла сверены. Чтобы не
копировать ещё 3,95 ГБ на почти заполненную microSD, использованы штатные параметры
`--offline`, `--runtime-manifest`, `--runtime-archive` с уже находившимися на карте
точными входами кандидата. Это обновление существующей установки, не новый сброс
до голой Armada и не проверка распаковки всего пользовательского архива на Flip.

- DuckStation действительно скачан установщиком с закреплённого официального
  GitHub asset. Его размер и SHA-256 совпадают с descriptor.
- Все семь установленных AppImage имеют `0755` и совпадающие SHA-256; ошибочные
  `0644` у DuckStation/eden/rpcs3 исправлены через установочную транзакцию.
- Software audit и runtime audit: `ready`, без проблем. Незавершённых журналов нет,
  предыдущее поколение сохранено. Оболочка остаётся из `2a6c9c9b`.
- До открытия оболочки сверены 28 файлов личной базы, профиля, настроек и входов:
  все побайтово неизменны. Содержимое и их индивидуальные хеши не публикуются.
- Отдельная сессия снова открыла настоящий Home; Plasma отсутствует, первый кадр
  подтверждён, выбран private runtime-home, загрузочный выбор TrainerOS сохранён.
  В интерфейсе сохранились тестовый профиль и баланс. Через действия NES Pong
  доступны Lobby/выбор Emulator multiplayer и Remote Play. Лобби не создавалось,
  приглашения не отправлялись; Prepare/Ready/Start в этом проходе не проверены.

Первоначальное административное переключение Desktop через SSH завершило launcher
без освобождения runtime lease. Setup правильно отказался продолжать. После
настоящей перезагрузки переход выполнен через обычное меню TrainerOS: lease снят
штатно, установка завершилась. Защитный marker вручную не удалялся; это не ошибка
проверенного перехода через интерфейс и не новая игровая приёмка.

## Что остаётся

Odin не использовался. Новый парный матч, разные сети, физические проверки и
проход всех семейств через Prepare/Ready/Start/Exit не выполнялись. Прежние игровые
результаты неизменённых runtime сохраняются. Это не обещание multiplayer для всех
solo-платформ. По последнему решению владельца отсутствие всех запланированных
функций не блокирует альфу; source/license материалы и публичный GitHub/OTA выпуск
остаются отдельной работой. Публичный выпуск не выполнен.
