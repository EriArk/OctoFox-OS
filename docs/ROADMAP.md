## Текущий выбор владельца — пре-бета и отдельная сессия, 3 ноября 2026

Позднейшее уточнение: альфа выпускается с явно указанным неполным функционалом.
Завершение всех платформенных режимов не блокирует выпуск. Подготовка уже
работающих маршрутов в Setup и сохранение пользовательских данных обязательны.

Установщик размещает собственные эмуляторы рядом с пользовательскими и выбирает
отдельную сессию TrainerOS по умолчанию при первой системной интеграции. На Flip
проверены настоящая перезагрузка, возврат в Desktop и входы в сервисы; полный
кандидат собран, публичного выпуска пока нет. ScreenScraper application access
и hybrid Setup доставлены. Следующие оставшиеся пункты — завершение source/license
комплекта и GitHub release/OTA. [Текущее состояние и границы проверок](CURRENT_TASKS.md).
Транспорт большого Setup частями и три новых source capsules подготовлены;
[результат](evidence/2026-11-03-release-delivery/README.md) не означает публикацию.
Для 58/76 старых cores собраны inputs; для остальных 18 теперь [собраны отдельные
кандидаты с известными исходниками](evidence/2026-11-04-core-rebuild/README.md). Следующий
шаг — private RetroArch на Flip и продвижение проверенных замен в Setup, затем
оставшиеся материалы/модели и GitHub/OTA. Старый набор пока сохранён.

**Решение владельца, 21 октября 2026:** глобальные планы, этапы и обязательная
очередь больше не используются. Работа временно ведётся по готовности функций.

Единая [карта готовности с галочками](FEATURE_READINESS.md) сохраняет сделанные,
недоделанные, несделанные и непроверенные части. Требования остаются в профильных
[issues](https://github.com/EriArk/TrainerOS/issues) и технических документах.
Порядок строк карты не является планом исполнения.

Прежние последовательности из ROADMAP, AGENTS, issues и датированных отчётов
не задают следующий этап. Сохраняются требования, реальные зависимости,
результаты проверок и ограничения реализации. Категории «отложено» нет.

Этот файл оставлен как указатель для существующих ссылок. История планов
доступна в Git; новый глобальный план без решения владельца не создавать.
