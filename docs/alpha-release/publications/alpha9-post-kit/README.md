# OctoFox OS — Alpha 9 post kit

**Publication working branch, 22 November 2026.** These are the 13 original, unchanged images chosen for the Discord/Reddit announcement, plus publication text.

## Contents

- `01_Reddit_and_Discord/`: 10 ordered images, starting with the OS interface and moving into Ship Home, Bazaar and Crates games.
- `02_Discord_Extras/`: 3 optional additional images.
- `texts/DISCORD_ANNOUNCEMENT_APPROVED.md`: the approved English Discord announcement from the discussion.
- `texts/REDDIT_DRAFT_FOR_REVIEW.md`: proposed Reddit draft. **This one is not approved yet.**
- `REVIEW_GALLERY.html`: self-contained **offline** preview when accompanied by the image directories.
- `selection.json`: original source paths, file order and Git blob hashes.
- `create_zip.py`: creates `OctoFox_OS_Alpha9_Post_Kit.zip` with images and both texts.

The files were copied from the existing Alpha 9 public screenshot gallery without changing their bytes. Some experiences, including the Bazaar and Crates games, are separately installed/upgraded and not automatically part of the OS update.

Public links belong in posts:
- Website: https://abysstail.art/en/projects/octofox-os
- Community: https://discord.gg/xBN9DXt8Q

This is staging content for review, **not an OS release**. Never merge the publication kit into `main` just to publish an announcement.
