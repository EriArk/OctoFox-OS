# Оригинальная графика во всём адаптере

3 ноября 2026. Владелец потребовал применять оригинальный набор везде,
в том числе в существующих профилях, где оставались старые частные пакеты.

## Изменение

- Оба поставщика графики по умолчанию используют `ArtSource::Original` и не
  загружают установленный индекс, выбранную иллюстрацию или старый SHA-image URL.
- Общая цепочка обслуживает Home, Party/Boxes, Guide, picker, Hall, Playroom,
  Practice и Link. Названия/точные формы/характеристики/сохранения не изменяются.
- Вместо прежних копий игровых значков в runtime входят восемь оригинальных
  абстрактных медальонов. Сохранены названия, ID, порядок и биты получения.
- Частные пакеты и choices остаются на диске. Внутренний режим Imported с прежними
  проверками доступен для будущей явной активации; UI-переключатель отложен.
- Старые исходные эмблемы и attribution остаются историческим материалом в Git,
  но исключены из ресурсов приложения. Credits описывает текущие рисунки.
- Дополнительно заменены рисуемые QML-кодом медсестра и капсулы Care Center:
  собственный кубический смотритель и прямоугольные модули. В магазине — робот
  той же оригинальной серии. Комнаты и действия сохраняют существующую компоновку.

## Проверка и доставка

ARM Release, Qt 6.11.2: прошли `sprite_art`, `classic_art` и
`GameProgressTests::badgeArtwork`. Новые проверки устанавливают настоящий
тестовый legacy-index/choices/images и подтверждают оригинальные иллюстрации,
clips/portraits в PartyPresentation, отказ от старого SHA-URL и неизменность файлов.
Прежние проверки импортера выполняются с явным `ArtSource::Imported`.
Тест значков проверяет загрузку SVG, прозрачность/непустое содержимое,
семантический порядок/earned-mask и отсутствие старых PNG в qrc.

Прошли `pokemonWorkspacesAtHandheldSizes` (48 кадров) и
`homeAdapterHasSeparateContentAndActions` (18 состояний): обе темы,
компактные размеры, полная/пустая команда и длинное название. Просмотрены
команда, Guide и кадр моргания Playroom. Fixture не подменяет реальное сохранение.
Устранено разрешение сгенерированного build/qmldir вместо изолированного UI-модуля.

После замены смотрителя/торговца повторно прошли 48 кадров workspace fixture.
Эта правка затронула только два QML-экрана; C++-проверки не повторялись без причины.

## Установлено и просмотрено

Одинаковый production ARM Release (`BUILD_TESTING=OFF`) установлен на Flip/Odin:
`0459f8063b3a182bf58e25601e82f79a91603108b56e62ebad8b4225b87584e0`.
Сборка выполнялась на microSD Flip, Odin для сборки не использовался.
Резервные исполняемые файлы и снимки данных сохранены. [Запись доставки](delivery.json).

На Flip проверен обычный профиль с существующими старыми пакетами: Home с шестью
существами и восемью новыми медальонами, настоящая команда, Boxes, Guide,
анимация Playroom, выбор любимого существа с отменой редактирования, Care Center
и магазин. Hall открывается, но существующий архив пуст: это не проверка
реального заполненного Hall. Текст/числа происходят из существующих данных;
лечение, покупка, перенос, новый save-write и сетевой бой в этом проходе не запускались.
Practice/Link используют общие projections; их отдельная сетевая/игровая приёмка
этими кадрами не подтверждается.

На Odin проверен обычный Home, затем отдельный ephemeral-пример установленной
сборки: Home, Party, Care Center и Playroom. Это sample-данные, не новая реальная
команда Odin. Временный процесс закрыт, обычный Home восстановлен. На обоих
устройствах остался ровно один обычный процесс с итоговым SHA-256.

- [Торговец, компактный светлый fixture](shops-light-760.png).

При установке проверки БД/существующих строк, настроек и avatar pack прошли.
После UI-проверки побайтовая сверка настроек ожидаемо отличается только состоянием
Companion. На Odin флаг `content_available` восьми Steam-записей изменился 1→0;
в сохранённом до установки `config.available` всех восьми уже было false.
Это согласование кеша с прежней доступностью, не удаление: файлы ACF существуют,
все ID и остальные поля adventures совпадают. Все прежние защищённые строки
save/session/profile/worlds сохранены. Эти отличия записаны отдельно от проверки установки.
Три индекса/файла
choices частных пакетов на каждом устройстве имеют прежние SHA-256. Громкость
сохранена: Flip 20%, Odin 0%. В последних 300 journal-строках каждого обычного
процесса нет ReferenceError/TypeError, binding loop и ошибок присваивания QML.
Оба устройства оставлены на обычном Home. Частные скриншоты профилей в Git не добавлены.

Само изменение визуальных providers не является новой приёмкой семантических
записей сохранения, сетевых боёв или всех публичных материалов #116.
