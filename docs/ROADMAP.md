**Решение владельца, 21 октября 2026:** глобальные планы, этапы и обязательная
очередь больше не используются. Работа временно ведётся по готовности функций.

Единая [карта готовности с галочками](FEATURE_READINESS.md) сохраняет сделанные,
недоделанные, несделанные и непроверенные части. Требования остаются в профильных
[issues](https://github.com/EriArk/TrainerOS/issues) и технических документах.
Порядок строк карты не является планом исполнения.

Прежние последовательности из ROADMAP, AGENTS, issues и датированных отчётов
не задают следующий этап. Сохраняются требования, реальные зависимости,
результаты проверок и ограничения реализации. Категории «отложено» нет.

Этот файл оставлен как указатель для существующих ссылок. История планов
доступна в Git; новый глобальный план без решения владельца не создавать.
