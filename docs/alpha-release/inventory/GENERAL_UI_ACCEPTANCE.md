# Общий UI — физическая приёмка перед публикацией

**Составлено после code-аудита 2026-11-03. Все пункты ниже пока `OPEN` для итоговой альфа-сборки.** Не выполнять опасные power/suspend-тесты без отдельного согласования.

Для любого закрытого пункта указать: **commit / build, устройство, ОС, дата, test operator, результат, ссылку на evidence**; частные проверки не переносить автоматически на другие устройства.

## Навигация и оболочка

- [ ] Home/Games/условный GameHub/Online/Apps имеют правильные подписи и нет пустого «фальшивого» tab
- [ ] L1/R1, L2/R2, экранный touch, A/B/Select и контекстные действия работают; после возврата фокус в ожидаемом месте
- [ ] Верхняя полоса, профиль, Sparks и колокольчик не перекрываются на 800×450, 960×540 и 1280×720
- [ ] X → Quick Apps, Y → Recent/Favorites, запуск/сворачивание/повторное открытие не теряют процесс
- [ ] При пустой библиотеке, без друзей и без RA показаны корректные empty states
- [ ] При переключении вкладок сохраняются выбранная коллекция/платформа и scroll
- [ ] Уведомления открываются/удаляются, входящий вызов управляется без зависших модалок

## Home и профиль

- [ ] На Home показаны игра, Play/Return, друзья, достижения, Screens и выбранный widget
- [ ] Встроенные Home widgets переключаются, настройка переживает рестарт
- [ ] Переходы Home → Messages / Achievement / Screens / Lobbies возвращают пользователя назад
- [ ] Профиль открывается и закрывается, корректно показывает offline/unauthorized состояния
- [ ] Wardrobe, история, RA, профильные настройки не ломают Home при недоступном сервере

## Games

- [ ] Создание/редактирование коллекции, открытие платформы, возврат в корень
- [ ] Wheel/List/Shelves/Grid, поиск, фильтр, избранное, изменение вида и scroll
- [ ] Контекстное меню Game/Library/View показывает только доступные действия
- [ ] Обработка без ROM/BIOS, Steam-игры, недостатка прав, отмена import/edit
- [ ] Проверен реальный запуск, выход и сохранность истории на конкретной игре
- [ ] Проверен/исправлен текст «Start → Library» в пустом состоянии

## Online/Chats (без аудита мультиплеера)

- [ ] Вход Fluxer в чистом профиле, выход/повторный вход, отсутствие сети
- [ ] Messages: выбор диалога, отправка текста, статус доставки, Back
- [ ] Communities: список, открытие канала, действия и отсутствие прав
- [ ] Discover: People / Communities / Recently together / поиск / empty/error
- [ ] Bazaar честно показывает заглушку, ничего похожего на рабочую торговлю
- [ ] Входы Lobby и Crates открываются, но их содержимое проверяется в отдельных матрицах

## Apps и Settings

- [ ] Реальный запуск 2+ внешних приложений, возврат, minimize/close и Quick Apps
- [ ] Browser с фактическим WebEngine: вкладки/история/закладки/сайты/файловый диалог
- [ ] Files: места, microSD, папки, открытие, разрешения, безопасные файловые операции
- [ ] Start: edit/move/resize/hide/add widgets и сохранение нескольких страниц
- [ ] Start: Wi-Fi/Bluetooth, audio output, микрофон, Sources; доступные/недоступные устройства
- [ ] Settings: шесть категорий, все страницы, индикация unavailable, Back
- [ ] Тема, масштаб, контроллер, Game input и библиотечные настройки сохраняются после перезапуска
- [ ] System/Updates отображает конкретную версию; переход Desktop/Steam охраняется корректно

## Замечания к выполнению

Существование сценариев в `tests/ui/` само по себе не закрывает чекбоксы. Датированные результаты Flip/Odin читать отдельно: [PROJECT_STATUS](../../../PROJECT_STATUS.md), [PREBETA_RELEASE_RU](../../PREBETA_RELEASE_RU.md), [evidence](../../evidence/). При старте следующего этапа сделать **отдельную таблицу Crates**, затем **отдельную таблицу мультиплеера** с точными играми/платформами/режимами/числом игроков/сетью.
