# Подготовка игр и BIOS-паки — 2 ноября 2026

## Реализовано

Обычный экран **Settings → Games & library → Library → Game preparation**:
платформы со статусами слева, имена файлов и Import справа, импорт общего пака
сверху. Сервисы Wii / 3DS / Wii U находятся в той же правой панели. Неполная
подготовка и непроверенный вход дают жёлтое предупреждение. Наличие файлов
не выдаётся за проверенный вход или совместимость игры.

Переиспользуются общие File Picker, Downloads и ArchiveExtractor. Известные
BIOS распознаются по сумме, остальные описанные файлы — по имени/размеру.
Импорт сохраняет существующие отличающиеся файлы и неоднозначные кандидаты.
Архив отправляется в корзину только после полного успешного импорта и
регистрации runtime. Непригодный профиль эмулятора не разрешает импорт
в каталог по умолчанию. Собственные BIOS/NAND/ключи не включены в Git.

## Проверки

- `GamePreparationTests`: **27 passed, 0 failed**. Файлы, ZIP/7z с изменённым
  расширением, контрольные суммы, отмена, конфликты, неоднозначность, обход
  путей, сохранность оригинала, слияние папок, безопасная корзина, Sega CD
  registration/backup, native пути, picker и состояния платформ/Online.
- `tools/export-game-adapters.py` / `tools/check-adapter-knowledge.py`:
  снимки и knowledge register проверены.
- На Flip/Odin удалённым вводом открыт настоящий экран: выбор 3DS, короткие
  имена, значки, переходы между панелями и прокрутка к четырём Online-действиям.
  На Flip открыты и отменены оба picker; Check Online оставляет тот же экран.
  Личные BIOS или учётные данные при этих проверках не импортировались.

QML-сценарий использует отдельный временный runtime и синтетические файлы.
Проверка выявила ошибку отложенного обращения к уничтоженному делегату;
отложенная прокрутка переведена на методы корня экрана с проверкой объекта.
Финальный QML-прогон после этой правки **не выполнен**. Также исправлен сам
сценарий: перед нажатием третьего файла он прокручивает список контроллером
и ищет delegate по дереву визуальных элементов, а не QObject parents.
Предыдущий прогон с ошибкой не считается пройденным.

## Поставка и сохранность

Release ARM64 собирается в отдельном каталоге на Flip. Общий каталог другого
чата после проверки обнаружен изменённым: его результат не устанавливался,
сборка повторена из проверенного снимка в изоляции. Windows Debug linker
потребовал уменьшить расход памяти; это не изменение production-настроек.
Docker на ПК не использовался.

На обеих портативках уже проверены сохранность настроек, исходных строк
SQLite, собственных аватаров и хешей вспомогательных программ. Предыдущие
оболочки и снимки данных сохранены. Odin остаётся на 0% громкости, Flip — 20%.
Свежая интеграция Companion из main сохранена; другие игровые runtime не заменялись.

## Границы

Это подготовка описанных файлов и встроенные настройки Online, не автоматический
вход в Pretendo/Wiimmfi/WiiLink. Цельные Wii NAND/Vita PUP, Artic/Nimbus и
остальные native-рецепты остаются незавершёнными. RAR читает существующий
libarchive; отдельная RAR-фикстура в этом наборе не выполнялась.
