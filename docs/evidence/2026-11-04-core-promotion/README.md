## Защита продвижения

`packaging/software/core_promotion.py` предоставляет две последовательные операции:

1. `component(...)` принимает прежний component/manifest/source binding, точный
   candidate archive/report, native ABI report и новый каталог вывода. Сверяет
   прежний бинарник, выбранную сборку, commit, patches и hash проверенного core.
   Проверяет все вложения до извлечения; посторонние/повторные файлы запрещены.
2. `media(...)` принимает прежний runtime с его identity, результат первого шага,
   тот же candidate и новый путь архива. Заменяет только два component entries и
   добавляет точный build/source kit, новые bindings и build records. Перечитывает
   весь итоговый архив. Подписание выполняет обычный `runtime_set.publish_manifest`,
   сборку Setup — `offline_setup.build` с заранее подписанным manifest.

Операции не заменяют существующий каталог/архив и сами ничего не устанавливают.
Сборочные записи сохраняют исходные `installed: false`/`runtimeAccepted: false`:
это исторические свойства build attempt, не актуальный статус установленной системы.
Актуальная доставка записывается отдельно ниже.

**27 тестов Windows и 27 Linux прошли**, включая семь проверок продвижения:
изменённые архивы, чужой прежний бинарник, несовпадающий native hash, лишнее ядро,
другая patch list, сохранение остальных файлов и подмена компонента перед упаковкой.
[Windows](windows-tests.txt), [Linux](linux-tests.txt).

Обновление **sequence 12 → 13 завершено через обычный GUI Setup**. Из оболочки
вышли штатным Home/Start → Switch → Desktop → Continue; lease-файлы вручную не

системные стадии прошли через обычные диалоги авторизации Armada.

Для экономии места на microSD перенесены runtime и точный небольшой bootstrap
из проверенного Setup; подписанный Software archive `2a6c9c9b` уже находился на
Flip и повторно использован через штатный `--offline`. Это обновление существующей
установки, **не повторная чистая установка полного tar с нуля**.

- Оба аудита — `ready`, все 76 установленных core hashes совпали с новым binding.
- 31 личный файл (конфигурация, локальные базы и JSON) совпал с контрольным срезом
  после штатного закрытия оболочки и до установки. Игры/BIOS не переносились и не
  удалялись; это сравнение не объявляется полным хешированием всей личной библиотеки.
- Предыдущий подписанный sequence 12 и его Software pairing доступны; проверены
  recovery blobs всех 18 прежних ядер. Фактический откат 13 → 12 в этом проходе
  не выполнялся. Транзакций, требующих восстановления, нет; свободно 16,24 GiB
