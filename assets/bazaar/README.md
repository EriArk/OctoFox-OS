# Bazaar cover art

`official.png` is an original illustration generated with OpenAI image generation
on 2026-11-10 for the owner-approved fantasy Bazaar catalogue. It is static cover
art, not a screenshot or a claim that the game/world already exists. No reference
images, third-party characters, logos or game assets were supplied. The exact
prompt is recorded in `prompt.txt`. Bundled under the repository asset terms.

Player cards in isolated UI fixtures reuse the existing original profile-scene
art. They are not advertised player worlds in the normal application.


`grove.png` and `harbor.png` are original player-card illustrations generated with
the built-in OpenAI image_gen tool on 2026-11-10. Full prompts are recorded in
[player-prompts.json](player-prompts.json). No references, third-party characters
or logos were supplied. These free catalogue decorations do not grant any paid
profile scene and do not claim that a playable world has been built. The market
preset reuses `official.png`; all three are bundled under the repository asset terms.
