## Реализация и проверки

`packaging/software/core_sources.py` проверяет хеш component archive, полный набор
`.so`, ARM64 ELF, размер/хеш каждого бинарника, закреплённый маркер и commit.
Отдельно сверяются retained build records, source capsule repository/commit/hash,
справочный рецепт и локальные патчи. При упаковке каждое вложение повторно читается
и сверяется. Чужой/повторный core, неверный hash, ошибочная ревизия и unsafe path
отвергаются; существующий output сохраняется.

**21 Linux-проверка** прошла, включая 9 новых core-source и 12 source-capsule.
Те же две группы прошли на Windows. [Лог Linux](linux-checks.log).
Реальный компонент проверен целиком, source bundle собран и повторно прочитан.
Два обнаруженных случая исправлены, а не скрыты:

- Citra gitlink указывает на официальный SoundTouch в Codeberg. Добавлен только
  точный repository URL, с проверкой отклонения посторонних адресов. Происхождение
  подтверждает [сайт SoundTouch](https://surina.net/soundtouch/sourcecode.html).
- Строка Citra revision непосредственно следует за двоичной таблицей и не имеет
  начального NUL. Проверка допускает такой layout, сохраняя конечный NUL, точный
  хеш всего ELF и связь marker/commit. Добавлен regression test.

Справочная карта core → repository взята из `libretro-super`
`43c6483ae90d5c5a9a6073465ec0902515a6ef8a`:
[upstream rules](https://github.com/libretro/libretro-super/blob/43c6483ae90d5c5a9a6073465ec0902515a6ef8a/rules.d/core-rules.sh).
Это текущая карта проекта, не выдуманный исторический build recipe установленного
бинарника. Наши известные handheld recipes/patches приложены отдельно.

## Что не считается закрытым

Найденная Git-ревизия доказывает upstream input, но не полноту исходников локальных
изменений, compiler/link flags, внешних библиотек или всей поставки. У
VirtualJaguar есть `dirty`, а соответствующий diff ещё не определён. Для linked
mGBA приложен наш patch; его наличие не заменяет полного build review. Поэтому
`completeBinaryBuildReviewed` и `redistributionReviewed` остаются `false`.

У 26 cores exact input пока неизвестен. Отдельно сохранены [72 записи `.info`](info-hints.json)
с хешами из того же component archive. Их версии устарели в ряде случаев:
DOSBox Pure сообщает `0.9.9`, бинарник — `1.0-preview6`; Stella сообщает `6.6`,
бинарник — `8.0_pre`. Эти метаданные не используются как доказательство версии
или окончательное лицензионное разрешение.

Отсутствие exact-source не является одинаковым юридическим условием для всех
библиотек. Например, [MIT](https://opensource.org/license/mit) требует сохранения
copyright/permission notice; нельзя автоматически навязывать ей требования
copyleft. У GPL/MPL и отдельных non-commercial компонентов проверяются их
собственные условия и зависимости. Таблица `.info` сама по себе эти условия
не закрывает. Полнота исходников и воспроизводимость сборки также различаются.

Далее: восстановить происхождение оставшихся cores и неизвестных локальных
изменений либо закрепить получение точных оригинальных пакетов из upstream,
где оно действительно доступно; завершить необходимые исходники/notices
зависимостей Flatpak/AppImage/Python и упаковку аватара, затем GitHub/OTA.
Неполные функции мультиплеера не добавлены в условия альфы. Flip/Odin и публичный
release/feed в этом проходе не менялись.
