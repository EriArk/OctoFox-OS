# Прямой Home, звонки и два колокольчика — 2 ноября 2026

Установлено на Flip/Odin, включая окончательное оформление всплывашки.
Исходники финальной сборки — `0dabec03`: core плюс сохранённая параллельная
подготовка DS `2d3152c5` и Nintendo Online `6da4ee7f`. Новые DS/Nintendo Online
runtime-пакеты этим проходом не устанавливаются.

## Контракт

- Home без игры → главный экран, повторное Home ничего не открывает.
- Живая/свёрнутая игра → существующее игровое меню, без промежуточного Now.
- Верхний колокольчик → inbox под собой; нижний после часов → inbox над собой.
  Содержимое и выбранная запись общие. Вторая иконка перемещает открытый inbox.
- Обычные уведомления и входящие звонки → справа снизу над нижней строкой.
- Ответить/Отклонить доступны прямо в звонке и inbox. Нажатие тела плашки
  не отвечает автоматически. Смахивание или Back только скрывает всплывашку.
- Скрытая всплывашка не появляется снова при повторном snapshot/переподключении.
  Подтверждённое окончание звонка разрешает новую всплывашку того же собеседника.
  Другая учётная запись не наследует скрытие; устаревший ID не отвечает на другой звонок.

## Последнее уточнение владельца

Жёлтая toast-плашка первой поставки отклонена. Финальная теперь использует `Theme.paper`,
`Theme.divider`, неброский колокольчик и текст общей темы, без коричневой рамки.
Настоящий QML повторно отрендерен и просмотрен в светлой/тёмной темах, без warnings.
После совмещения с актуальным main повторены Interaction (59) и Social (208, один
Linux-only skip), собраны Windows и ARM. Повторная установка завершена на обоих.

Companion владелец **отложил до публикации в Crates**. Его ветка и незавершённая
подготовка пакета оставлены самостоятельной работой; модуль/пакет не включён в
эту поставку. Следующее действие — применить опубликованный Companion вместе
с его готовой поддержкой host, не подменяя это встроенным незавершённым виджетом.
