Dead Cells также перенесена с проверкой и сохранением прежнего пути Steam. В личную

Это подготовка устройства, не поставка игр/BIOS в дистрибутиве.

[Кандидат с composefs](candidate-composefs.json) действительно прошёл host probe,
подготовку шести Python-окружений, установку собственных файлов и всех 12 Flatpak refs.
Первый запуск из SSH не нашёл графический агент polkit; запуск через рабочий стол
открыл обычный диалог авторизации. Продолжение по журналу выполнило системную часть,
подтверждение runtime и активацию Software. Регистрация сессии затем остановилась:
частный staging-скрипт отфильтровал `.service`/`.conf`. **Чистая установка ещё не завершена**,
оболочка и игра не запускались. Ручной обход регистрации не засчитывается как приёмка.

Для следующего кандидата staging развёрнут из полного `git archive` каталогов
packaging/tests, без фильтра по расширениям. Bootstrap теперь заранее требует все
14 файлов сессии, включая службу и конфигурацию. [Восемь Linux-проверок](session-bootstrap-tests.log)
прошли; новая регрессия поочерёдно удаляет каждый обязательный файл и проверяет отказ
до создания bootstrap. Неполные кандидаты 01/02 не используются для выпуска.
Далее: полный архив → повтор чистого Setup → первый запуск/библиотека/BIOS → игра/возврат.
