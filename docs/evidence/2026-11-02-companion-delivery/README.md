# Companion: общая поставка на Flip/Odin — 2 ноября 2026

Совмещены main `8dcdfd0f` и подготовленная ветка Companion `4c2e3526`.
Сохранены прямой Home, два якоря inbox, нижние всплывашки и остальные изменения main.
Это установка оболочки и опубликованного пакета, не объявление полной готовности виджета.

## Исправленная интеграция

- QML touch вызывал неэкспортированный `dashboard.select`; метод сделан invokable.
- Сигнал care во время загрузки/выгрузки виджета повторно вычислял bindings
  `widgetPicking`/`live`/`Loader.active`; уведомление dashboard теперь отложено через Qt queue.
- Open из Crates сначала открывал picker, который оболочка закрывала вне Home.
  Выбор применялся неверно при сообщении об успехе. Crates/SDK теперь применяют
  проверенный ID атомарно; обычный выбор сохраняет проверки picker/владельца.
- Сохранённый ARM build имел пустой build type. Выполнена полная Release-сборка;
  [правило поставки](../../ARMADA_PLATFORM.md) теперь требует явного Release.

Геометрия/оформление `HomeCompanionWidget.qml` и `HomeCompanionScene.qml` относительно
подготовленной ветки не менялись. Прямоугольное отсечение поверхности при круглой
рамке — дефект renderer Companion. По указанию владельца создано
[Crates #2](https://github.com/EriArk/crates/issues/2), исправление здесь не выполнялось.

loops; присутствуют отдельные сетевые HTTP/2 Connection closed, поэтому
«журнал без ошибок» не заявляется.

## Ресурсы и оставшаяся работа

Две 10-секундные выборки процесса на Flip с финальной Release-сборкой:

| Home | CPU, проценты одного ядра | RSS, KiB |
|---|---:|---:|
| Companion, видимая анимация | 112,0 | 782672 |
| Clock после переключения | 36,2 | 785716 |

Это наблюдение процесса, не FPS/нагрев/батарейный тест. RSS после переключения
включает удержанные кеши. Release не устранил высокую стоимость анимированного
аватара: снижение нагрузки остаётся открытым следующим техническим шагом.
Odin не использовался для нагрузочных/дисковых тестов.

Физические кнопки/касания, длительная работа, реальные новые игровые достижения,
ретаргет внешних клипов и исправление углов остаются открытыми. Сон/lid устройств
не тестировались. Предметы, не включённые renderer, не объявляются доставленными
реакциями. Детальная карта — [Home Companion](../../HOME_COMPANION.md).
