# Альфа: проверка перед публикацией

Это **контрольный лист, не заявление о пройденном релизе**. Незаполненный пункт — `OPEN` до отдельной проверки. `PARTIAL` не равен `PASS`. Даты и блокеры обновлять по мере работы.

**Политика Alpha:** цель — **дать людям работоспособную тестовую сборку**, а не завершить все функции. До выпуска обязательны минимальные установочный/игровой smoke, базовая безопасность данных и законность распространяемых материалов, документация ограничений и канал приёма ошибок. Подробные проверки совместимости, игр, устройств и сетей — после выпуска, вместе с пользователями. `OPEN` по отдельной экспериментальной функции **не блокирует** релиз, если она правильно обозначена.

**Начальный риск (срез 2026-11-03):** [PREBETA_RELEASE_RU](../../PREBETA_RELEASE_RU.md) и [PROJECT_STATUS](../../../PROJECT_STATUS.md) ещё не подтверждали публичный завершённый выпуск, публичные assets/feed и полный licensing/source gate. Перед любым публичным утверждением проверить свежие факты.

## Решение о публикации

- **GO (Alpha)** — ключевой пользовательский путь и базовая безопасность подтверждены; непроверенные функции честно отмечены, тестирование открыто сообществу.
- **LIMITED GO** — альфа для конкретного проверенного железа/маршрута; остальная функциональность доступна экспериментально, без обещаний надёжности.
- **NO GO** — есть риск потери данных, недостоверный пакет/источники, провал обязательного пути установки либо другое критическое препятствие.

Решение принимать **по конкретному кандидату и целевой конфигурации**, а не по общему ощущению готовности проекта.
